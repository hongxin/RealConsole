# 项目结构说明

本文档详细说明 RealConsole 项目的目录组织结构和文件分类规范。

---

## 📁 总体结构

```
RealConsole/
├── src/                    # 源代码目录
├── tests/                  # Rust 集成测试
├── examples/               # 示例代码
├── scripts/                # 脚本工具
│   ├── test/              # 测试脚本
│   └── utils/             # 工具脚本
├── docs/                   # 项目文档
├── config/                 # 配置文件
├── locales/                # 国际化资源
├── benches/                # 性能基准测试
├── target/                 # 编译输出（ignored）
├── temp/                   # 临时文件（ignored）
└── [配置文件]             # 项目配置文件
```
