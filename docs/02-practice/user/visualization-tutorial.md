## 第一章：道 - 可视化的本质

### 1.1 什么是数据可视化？

**核心理念**："见数知理" - 通过视觉将数据转化为洞察

```
数据（阴）→ 图表（阳）→ 洞察（升华）
```

**易经智慧**：
- **变易**：数据是流动的，图表随数据而变
- **不易**：可视化的本质是"理解"，这是不变的
- **简易**：复杂的数据，简单的呈现

### 1.2 RealConsole 可视化能力概览

**8 种图表类型**（按复杂度递增）：
1. **折线图** (Line) - 趋势变化
2. **柱状图** (Bar) - 数值对比
3. **饼图** (Pie) - 占比分布
4. **散点图** (Scatter) - 相关性分析
5. **面积图** (Area) - 累积趋势
6. **气泡图** (Bubble) - 三维数据
7. **雷达图** (Radar) - 多维对比
8. **热力图** (Heatmap) - 数据密度

**3 种导出格式**：
- **CSV** - 数据源（可再编辑）
- **PNG** - 光栅图（网页展示）
- **SVG** - 矢量图（论文/PPT）

### 1.3 快速开始

**前提条件**：
```bash
# 1. 安装 RealConsole
make install

# 2. 配置 LLM（可选，用于智能图表推荐）
realconsole wizard

# 3. 启动 Web 终端
export DEEPSEEK_API_KEY="your-key-here"
realconsole web
```

**访问**: http://127.0.0.1:7788

## 第二章：德 - 基础图表

> **德**：数据的真实性，选择最合适的基础图表

### 2.1 折线图（Line Chart）- 趋势之道

**适用场景**：时间序列、趋势变化、连续数据

**命令格式**：
```bash
!chart line \
  --title "月度销售趋势" \
  --x-labels "1月,2月,3月,4月,5月,6月" \
  --series "销售额:120,132,145,138,155,170"
```

**参数说明**：
- `--title`: 图表标题
- `--x-labels`: X 轴标签（逗号分隔）
- `--series`: 数据系列（格式：名称:值1,值2,...）

**实战示例 1：股票价格走势**
```bash
!chart line \
  --title "特斯拉股价（2024年1月）" \
  --x-labels "1/1,1/5,1/10,1/15,1/20,1/25,1/31" \
  --series "开盘价:248,251,245,252,258,262,265" \
  --series "收盘价:250,249,247,255,260,264,268"
```

**实战示例 2：网站访问量**
```bash
!chart line \
  --title "每日访问量统计" \
  --x-labels "周一,周二,周三,周四,周五,周六,周日" \
  --series "UV:1200,1350,1420,1580,1650,890,720" \
  --series "PV:3500,4200,4800,5100,5600,2400,1800" \
  --smooth  # 平滑曲线
```

**哲学思考**：
- **连续性**：折线图体现"易经"中的"变易"，万物皆变
- **趋势性**：上升或下降，阴阳消长的视觉呈现

- **差异性**：柱状图体现"素书"中的"义"，分辨差异、明确等级
- **对比性**：高低之别，强弱之分，一目了然

```bash
  --labels "研发,市场,运营,管理,其他" \
  --series "预算:40,25,15,12,8"
```

**实战示例 2：流量来源**
```bash
!chart pie \
  --title "网站流量来源分布" \
  --labels "搜索引擎,社交媒体,直接访问,外部链接" \
  --series "流量:45,30,18,7"
```

**实战示例 3：时间分配**
```bash

  --title "每日时间分配（小时）" \
  --labels "工作,睡眠,学习,娱乐,其他" \
  --series "时间:8,7,3,4,2"
```

**哲学思考**：
- **整体性**：饼图体现"一分为三"，部分构成整体

**⚠️ 注意事项**：
- 分类不宜过多（建议 ≤7 个），过多则难以区分
- 不适合展示趋势变化，只展示某一时刻的占比

## 第三章：仁 - 进阶图表

> **仁**：服务用户理解，用更丰富的图表传递更多信息

### 3.1 散点图（Scatter Chart）- 相关之道

**适用场景**：相关性分析、异常值检测、分布模式

**命令格式**：
```bash
!chart scatter \
  --title "身高体重分布" \
  --x-name "身高(cm)" \
  --y-name "体重(kg)" \
  --series "男性:(170,65),(175,70),(180,75),(165,60)" \
  --series "女性:(160,50),(165,55),(170,60),(155,48)"
```

**数据格式**：`(x,y)` 坐标对，括号包裹，逗号分隔

**实战示例 1：房价分析**
```bash
!chart scatter \
  --title "北京二手房：面积 vs 价格" \
  --x-name "面积(㎡)" \
  --y-name "总价(万)" \
  --series "数据:(50,350),(70,520),(90,680),(110,850),(130,1020)"
```

**实战示例 2：广告投放效果**
```bash
!chart scatter \
  --title "广告投入 vs 转化率" \
  --x-name "投入(万元)" \
  --y-name "转化率(%)" \
  --series "搜索广告:(10,2.5),(20,3.8),(30,4.2),(40,4.5)" \
  --series "信息流:(10,1.8),(20,2.5),(30,3.0),(40,3.2)"
```

**实战示例 3：学习时间与成绩**
```bash
!chart scatter \
  --title "学习时间 vs 考试成绩" \
  --x-name "每日学习时长(小时)" \
  --y-name "成绩(分)" \
  --series "数据:(1,65),(2,72),(3,78),(4,85),(5,88),(6,92),(7,90)"
```

**哲学思考**：
- **关联性**：散点图揭示因果关系，"一即一切，一切即一"
- **离散性**：点状分布，体现万物的独立性与联系性

**观察要点**：
- **正相关**：右上倾斜，x ↑ → y ↑
- **负相关**：右下倾斜，x ↑ → y ↓
- **无相关**：随机分布，无明显规律
- **异常点**：远离主分布的点，值得关注

### 3.2 面积图（Area Chart）- 累积之道

**适用场景**：累积趋势、总量变化、堆叠对比

**命令格式**：
```bash
!chart area \
  --title "累积销售额" \
  --x-labels "1月,2月,3月,4月,5月" \
  --series "在线:100,120,150,180,220" \
  --series "门店:80,90,100,110,130"
```

**实战示例 1：用户增长**
```bash
!chart area \
  --title "用户数累积增长" \
  --x-labels "Q1,Q2,Q3,Q4" \
  --series "付费用户:5000,8000,12000,18000" \
  --series "免费用户:20000,35000,52000,70000"
```

**实战示例 2：能源消耗**
```bash
!chart area \
  --title "月度能源消耗（千瓦时）" \
  --x-labels "1月,2月,3月,4月,5月,6月" \
  --series "工业:1200,1150,1180,1220,1280,1350" \
  --series "商业:800,780,820,850,900,950" \
  --series "居民:500,480,490,510,540,580"
```

**哲学思考**：
- **叠加性**：多系列堆叠，体现"万物负阴而抱阳"
- **累积性**：面积代表总量，时间的积累产生价值

**与折线图的区别**：
- 折线图：强调趋势
- 面积图：强调总量 + 趋势

---

### 3.3 气泡图（Bubble Chart）- 三维之道

**适用场景**：三维数据可视化（x, y, size）

**命令格式**：
```bash
!chart bubble \
  --title "产品分析：价格 vs 销量 vs 利润" \
  --x-name "价格(元)" \
  --y-name "月销量(件)" \
  --series "产品A:(100,500,50000):(150,400,60000):(200,300,60000)" \
  --series "产品B:(80,800,64000):(120,600,72000):(160,450,72000)"
```

**数据格式**：`(x,y,size)` 三元组，括号包裹，冒号分隔多个点

**实战示例 1：公司对比**
```bash
!chart bubble \
  --title "科技公司：市值 vs 营收 vs 员工数" \
  --x-name "市值(亿美元)" \
  --y-name "营收(亿美元)" \
  --series "数据:(3000,400,180000):(2500,350,150000):(1800,280,120000)"
```
*注：size 代表员工数，气泡越大员工越多*

**实战示例 2：城市分析**
```bash
!chart bubble \
  --title "城市：GDP vs 人口 vs 面积" \
  --x-name "GDP(万亿)" \
  --y-name "人口(万)" \
  --series "数据:(4.3,2154,1641):(3.8,1756,2465):(2.9,1302,3340)"
```

**哲学思考**：
- **多维性**：三个维度，体现"天地人"三才
- **整体性**：位置 + 大小，信息密度更高

**设计建议**：
- size 差异不宜过大（建议 1:10 以内）
- 避免气泡重叠，适当调整数据范围

## 第四章：义 - 高级图表

> **义**：选择最合适的图表，让数据说话

### 4.1 雷达图（Radar Chart）- 多维之道

**适用场景**：多维度对比、能力评估、综合评分

```bash
  --series "员工A:90,70,85,60,80" \
  --series "员工B:75,85,90,70,75"
```

**实战示例 1：产品对比**
```bash
!chart radar \
  --title "手机综合评分" \
  --indicators "性能,拍照,续航,屏幕,外观,价格" \
  --series "iPhone 15:95,92,75,90,88,70" \
  --series "华为 Mate 60:90,95,85,88,90,75" \
  --series "小米 14:88,85,80,85,82,90"
```

**实战示例 2：团队能力**
```bash
!chart radar \
  --title "团队核心能力评估" \
  --indicators "技术能力,产品思维,执行力,创新力,协作力" \
  --series "前端组:85,75,90,80,88" \
  --series "后端组:92,70,85,75,80" \
  --series "算法组:95,65,75,90,70"
```

**实战示例 3：学生综合素质**
```bash
!chart radar \
  --title "学生综合素质评价" \
  --indicators "学业成绩,体育,艺术,社会实践,科技创新,道德品质" \
  --series "张三:92,78,85,88,90,95" \
  --series "李四:88,85,90,82,85,92"
```

**哲学思考**：
- **平衡性**：雷达图体现"中庸之道"，追求平衡发展
- **全面性**：多维度评估，避免"一叶障目"

**设计建议**：
- 维度数量：4-8 个最佳（过少信息少，过多难以辨识）
- 各维度量纲应统一（如都是 0-100 分）
- 适合展示相对差异，而非绝对值

### 4.2 热力图（Heatmap）- 密度之道

**适用场景**：数据密度、时间分布、相关性矩阵

**命令格式**：
```bash
!chart heatmap \
  --title "用户活跃度热力图" \
  --x-labels "周一,周二,周三,周四,周五,周六,周日" \
  --y-labels "00-06,06-12,12-18,18-24" \
  --data "[[0,0,12],[0,1,8],[0,2,15],[0,3,9]...]"
```

**数据格式**：`[[x_index, y_index, value], ...]`
- `x_index`: X 轴索引（从 0 开始）
- `y_index`: Y 轴索引（从 0 开始）
- `value`: 数值（会映射到颜色）

**实战示例 1：GitHub Contribution（简化版）**
```bash
!chart heatmap \
  --title "代码提交热力图（周 x 时段）" \
  --x-labels "周一,周二,周三,周四,周五" \
  --y-labels "上午,下午,晚上" \
  --data "[[0,0,5],[0,1,12],[0,2,8],[1,0,7],[1,1,15],[1,2,10],[2,0,6],[2,1,18],[2,2,12],[3,0,8],[3,1,20],[3,2,15],[4,0,4],[4,1,10],[4,2,6]]"
```

**实战示例 2：网站访问热力**
```bash
!chart heatmap \
  --title "网页点击热力分布" \
  --x-labels "首页,产品,博客,关于,联系" \
  --y-labels "顶部,中部,底部" \
  --data "[[0,0,850],[0,1,1200],[0,2,320],[1,0,680],[1,1,950],[1,2,280],[2,0,520],[2,1,780],[2,2,180],[3,0,320],[3,1,450],[3,2,120],[4,0,280],[4,1,380],[4,2,90]]"
```

**哲学思考**：
- **密度性**：颜色深浅体现"聚散离合"，数据的疏密分布
- **模式性**：热力图揭示隐藏的模式，"见微知著"

**设计建议**：
- 颜色方案：深色主题用"蓝-黄-红"，浅色主题用"蓝色渐变"
- 数据归一化：确保 value 在合理范围内（如 0-100）
- 适合大数据集，展示整体分布规律

### 4.3 混合图表（Mixed Chart）- 融合之道

**适用场景**：不同类型数据组合、主辅关系展示

**命令格式**：
```bash
!chart mixed \
  --title "销售额与增长率" \
  --x-labels "Q1,Q2,Q3,Q4" \
  --series "销售额:450,520,580,640:bar" \
  --series "增长率:15.5,13.5,11.5,10.3:line"
```

**语法说明**：
- 每个 series 可指定 `chart_type`（默认为主图表类型）
- 格式：`名称:值1,值2,...:图表类型`

**实战示例 1：销售分析**
```bash
!chart mixed \
  --title "月度销售分析" \
  --x-labels "1月,2月,3月,4月,5月,6月" \
  --series "销售额:120,132,145,138,155,170:bar" \
  --series "增长率:10,9,8,7,12,10:line"
```

**实战示例 2：电商数据**
```bash
!chart mixed \
  --title "用户行为分析" \
  --x-labels "周一,周二,周三,周四,周五,周六,周日" \
  --series "订单量:850,920,1050,1180,1320,1550,1420:bar" \
  --series "转化率:2.8,3.0,3.2,3.5,3.8,4.2,3.9:line"
```

**哲学思考**：
- **融合性**：混合图表体现"一分为三"，多元统一
- **主辅性**：柱状为主（总量），折线为辅（趋势），各司其职

**设计建议**：
- 不超过 2 种图表类型组合
- 左右 Y 轴分别对应不同数据类型
- 确保视觉层次清晰，避免混乱

## 第五章：礼 - 最佳实践与哲学思考

> **礼**：遵循可视化规范，让图表既美观又有效

### 5.1 图表选择决策树

```
数据类型
│
├─ 时间序列？
│   ├─ 是 → 折线图 / 面积图
│   └─ 否 → 继续
│
├─ 分类对比？
│   ├─ 是 → 柱状图
│   └─ 否 → 继续
│
├─ 占比分布？
│   ├─ 是 → 饼图
│   └─ 否 → 继续
│
├─ 相关性分析？
│   ├─ 是 → 散点图 / 气泡图
│   └─ 否 → 继续
│
├─ 多维对比？
│   ├─ 是 → 雷达图
│   └─ 否 → 继续
│
└─ 数据密度？
    └─ 是 → 热力图
```

### 5.2 可视化黄金法则

#### 1. 真实性原则（德）
- ✅ **数据真实**：不篡改、不夸大
- ✅ **Y 轴从 0 开始**：避免误导（柱状图尤其重要）
- ❌ **避免 3D 图表**：徒增复杂度，难以准确读数

#### 2. 简洁性原则（极简）
- ✅ **一图一主题**：不在一张图上塞太多信息
- ✅ **删除无用元素**：减少"图表垃圾"（chart junk）
- ✅ **颜色不超过 5 种**：过多颜色会分散注意力

#### 3. 清晰性原则（仁）
- ✅ **标题明确**：一眼看懂图表主题
- ✅ **坐标轴有单位**：如"销售额（万元）"、"时间（小时）"
- ✅ **图例清晰**：多系列时，图例不可少

#### 4. 美观性原则（礼）
- ✅ **配色协调**：深色主题用紫色系，浅色主题用蓝色系
- ✅ **字体合适**：标题 18px，正文 14px，不过大过小
- ✅ **留白充分**：图表边缘留白，避免拥挤

### 5.3 常见错误与纠正

#### ❌ 错误 1：饼图分类过多
```bash
# 错误示例：10 个分类的饼图
!chart pie \
  --title "市场份额" \
  --labels "A,B,C,D,E,F,G,H,I,其他" \
  --series "份额:15,12,10,9,8,7,6,5,4,24"
```

**纠正方法**：合并小分类
```bash
# 正确示例：合并为 5 个分类
!chart pie \
  --title "市场份额" \
  --labels "A,B,C,D,其他" \
  --series "份额:15,12,10,9,54"
```

#### ❌ 错误 2：折线图数据点过多
```bash
# 错误示例：100 个数据点的折线图（密密麻麻）
!chart line \
  --title "秒级数据" \
  --x-labels "00:00,00:01,00:02,...,01:39" \
  --series "数据:120,121,119,..."
```

**纠正方法**：聚合数据
```bash
# 正确示例：按分钟聚合
!chart line \
  --title "分钟级数据" \
  --x-labels "00分,10分,20分,30分,40分,50分,60分" \
  --series "平均值:120,125,128,130,135,138,142"
```

#### ❌ 错误 3：Y 轴不从 0 开始（柱状图）
```bash
# 错误示例：Y 轴从 90 开始，放大差异
# 视觉上 100 vs 95 看起来像 2 倍差距
```

**纠正方法**：让 Y 轴从 0 开始，展示真实差异

### 5.5 哲学思考：可视化的"三重境界"

#### 第一重：见山是山（初学者）
- 看到折线图，知道是趋势
- 看到柱状图，知道是对比
- **特点**：工具思维，按图索骥

#### 第二重：见山不是山（进阶者）
- 质疑图表：这个 Y 轴合理吗？颜色选择有偏见吗？
- 深入数据：为什么这里有异常点？趋势背后的原因是什么？
- **特点**：批判思维，透过现象看本质

#### 第三重：见山还是山（高手）
- 回归本质：数据可视化是为了"理解"，而非"炫技"
- 因地制宜：根据受众选择图表（技术人员 vs 管理层 vs 普通用户）
- **特点**：简约思维，大道至简

### 5.6 易经智慧在可视化中的应用

#### 变易：数据是流动的
- 实时更新图表，追踪变化
- 使用动态数据源（如数据库、API）

#### 不易：理解是目标
- 无论技术如何发展，可视化的核心目标永远是"让人理解"
- 不追求花哨，追求清晰

#### 简易：复杂问题简单化
- 10,000 行数据 → 1 张折线图
- 100 个维度 → 5-8 个核心指标的雷达图

### 5.7 素书智慧在可视化中的应用

#### 道：本质是理解
- 可视化不是为了"好看"，而是为了"看懂"

#### 德：数据真实性
- 不篡改数据
- 不使用误导性的坐标轴

#### 仁：服务用户
- 考虑受众的背景知识
- 提供必要的注释和说明

#### 义：选择合适的图表
- 时间序列用折线图，不用饼图
- 占比用饼图，不用折线图

#### 礼：遵循规范
- 使用合适的配色
- 保持一致的风格
- 添加标题、图例、单位

## 附录：快速参考表

### A. 图表类型速查表

| 图表类型 | 命令 | 适用场景 | 数据格式 |
|---------|------|---------|---------|
| 折线图 | `line` | 趋势变化 | `值1,值2,...` |
| 柱状图 | `bar` | 分类对比 | `值1,值2,...` |
| 饼图 | `pie` | 占比分布 | `值1,值2,...` |
| 散点图 | `scatter` | 相关性 | `(x,y),(x,y),...` |
| 面积图 | `area` | 累积趋势 | `值1,值2,...` |
| 气泡图 | `bubble` | 三维数据 | `(x,y,size):(x,y,size):...` |
| 雷达图 | `radar` | 多维对比 | `值1,值2,...` |
| 热力图 | `heatmap` | 数据密度 | `[[x,y,v],...]` |

### B. 命令参数速查表

| 参数 | 说明 | 适用图表 | 示例 |
|-----|------|---------|------|
| `--title` | 图表标题 | 所有 | `--title "销售趋势"` |
| `--x-labels` | X 轴标签 | line, bar, area | `--x-labels "Q1,Q2,Q3"` |
| `--labels` | 饼图标签 | pie | `--labels "A,B,C"` |
| `--series` | 数据系列 | 所有 | `--series "名称:值"` |
| `--x-name` | X 轴名称 | scatter, bubble | `--x-name "身高"` |
| `--y-name` | Y 轴名称 | scatter, bubble | `--y-name "体重"` |
| `--indicators` | 雷达维度 | radar | `--indicators "A,B,C"` |
| `--data` | 热力数据 | heatmap | `--data "[[0,0,5],...]"` |
| `--smooth` | 平滑曲线 | line, area | `--smooth` |

### C. 导出格式对比

| 格式 | 优点 | 缺点 | 适用场景 |
|-----|------|------|---------|
| **CSV** | 可再编辑、体积小 | 只有数据无图表 | 数据备份、Excel 分析 |
| **PNG** | 兼容性好、高清 | 放大会模糊 | 网页、PPT、社交媒体 |
| **SVG** | 无损缩放、矢量 | 某些软件不支持 | 论文、印刷、专业设计 |
