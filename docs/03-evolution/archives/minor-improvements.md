## 🔧 技术优化

### 错误提示优化

**改进前**:
```rust
return Err(anyhow!("Error: {}", msg));
```

**改进后**:
```rust
return Err(anyhow!(
    "{} {}\n  {}: {}",
    "✗".red(),
    "错误描述",
    "提示".yellow(),
    "解决建议"
));
```

**应用场景**:
- 配置文件错误
- LLM 连接失败
- 工具调用错误

### 路径处理标准化

**统一路径展示**:
```rust
fn display_path(path: &Path) -> String {
    if let Some(home) = env::var_os("HOME") {
        if path.starts_with(&home) {
            return path.strip_prefix(&home)
                .unwrap()
                .display()
                .to_string()
                .replace("", "~");
        }
    }
    path.display().to_string()
}
```

**好处**:
- 更简洁的输出
- 跨平台一致性
- 隐私保护（不暴露完整路径）
