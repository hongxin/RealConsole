## 🌟 核心特性：Web 终端

### 新增功能

RealConsole 现在支持通过浏览器访问的 Web 终端，允许在局域网中远程使用 RealConsole。

#### ✨ 主要特点

**1. 浏览器终端模拟器**
- 基于 xterm.js 的全功能终端
- 支持完整的终端特性（颜色、光标、滚动）
- 响应式设计，支持各种屏幕尺寸
- 现代化 UI，渐变背景，美观大方

**2. 完整的 RealConsole 功能**
- ✅ 系统命令（/help, /stats, /memory 等）
- ✅ Shell 命令（!ls, !pwd, !git 等）
- ✅ LLM 对话（需配置 API Key）
- ✅ 所有命令与本地版本功能一致

**3. 标准终端 UX**
- **提示符**: `%`（与本地版本一致）
- **历史命令**: ↑/↓ 键浏览历史
- **光标控制**: ←/→ 键移动，Home/End 跳转
- **飞轮动画**: 橙色旋转符号 + 模型名称（Deepseek/Ollama）
- **中文支持**: 完整的 UTF-8 字符支持

**4. 局域网访问**
- 支持本地访问（127.0.0.1）
- 支持局域网访问（0.0.0.0 绑定）
- 支持特定 IP 绑定（更安全）
- 灵活的端口配置

**5. 技术架构**
- **后端**: axum + WebSocket
- **前端**: xterm.js + 原生 JavaScript
- **协议**: JSON 消息格式
- **会话管理**: 独立 Agent 实例
- **资源嵌入**: 单一二进制文件

## 🚀 使用方式

### 本地访问（推荐）

```bash
# 启动服务
realconsole web

# 浏览器访问
http://127.0.0.1:7788
```

### 局域网访问

```bash
# 启动服务（允许局域网访问）
realconsole web --bind 0.0.0.0

# 浏览器访问
# 本机: http://127.0.0.1:7788
# 局域网: http://<你的IP>:7788
```

### 使用测试脚本

```bash
# 交互式测试脚本
./scripts/test/test_web_lan.sh

# 选择模式：
# 1 - 本地访问测试
# 2 - 局域网访问测试
```

## ⚙️ 配置说明

### 命令行参数

```bash
realconsole web [OPTIONS]

Options:
  -b, --bind <ADDRESS>    绑定地址 [默认: 127.0.0.1]
  -p, --port <PORT>       端口 [默认: 7788]
  -h, --help              显示帮助
```

### 配置文件

`realconsole.yaml`:
```yaml
web:
  enabled: true           # 是否启用（CLI 方式不需要）
  bind: "127.0.0.1"       # 绑定地址
  port: 7788              # 端口
  allowed_origins:        # CORS 配置
    - "*"                 # 允许所有源
```

## 🔐 安全特性

### 默认安全配置

- **默认绑定**: 127.0.0.1（仅本地访问）
- **显式开启**: 需要 --bind 参数才能局域网访问
- **CORS 配置**: 已配置允许跨域（开发友好）

### ⚠️ 安全提醒

**使用 `--bind 0.0.0.0` 时注意**:
- ❌ 会暴露在整个局域网
- ❌ 当前版本无身份验证
- ❌ 具有完整 Shell 执行权限
- ✅ 仅在受信任网络使用
- ✅ 不要在公网暴露

### 推荐做法

1. **本地开发**: 使用默认配置（127.0.0.1）
2. **团队协作**: 使用特定 IP 绑定（非 0.0.0.0）
3. **防火墙**: 配置防火墙限制访问
4. **即时停止**: 使用完毕立即停止服务

## 🔧 技术改进

### WebSocket 消息协议

**客户端 → 服务器**:
```json
{
  "type": "input",
  "content": "user command"
}
```

**服务器 → 客户端**:
```json
// 思考中（显示飞轮）
{ "type": "thinking", "model": "deepseek" }

// 普通输出
{ "type": "output", "content": "response text" }

// 流式输出
{ "type": "stream", "content": "chunk" }

// 错误信息
{ "type": "error", "content": "error message" }

// 清屏
{ "type": "clear" }
```

### 会话管理

- 每个 WebSocket 连接独立 Agent 实例
- 自动配置 LLM 客户端（Deepseek/Ollama）
- 会话 ID 跟踪（UUID）
- 会话时长统计

### 模型名称简化

复用命令行版本的 `simplify_model_name()` 逻辑：
- `deepseek-chat` → `deepseek`
- `qwen2.5:latest` → `qwen2.5`
- `claude-3-opus-20240229` → `claude-3`

## 🚧 已知限制

### 当前限制

1. **无身份验证** - 任何能访问 URL 的人都可以使用
2. **单用户模式** - 多个连接共享相同配置
3. **无 HTTPS** - 仅支持 HTTP（局域网使用）
4. **Tab 补全** - 暂未实现（未来计划）

### 未来计划

- [ ] 添加身份验证（用户名/密码）
- [ ] 支持 HTTPS/TLS
- [ ] Tab 补全支持
- [ ] 会话持久化
- [ ] 多标签页支持
- [ ] 文件上传/下载
