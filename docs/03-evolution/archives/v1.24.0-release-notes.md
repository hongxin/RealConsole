# RealConsole v1.24.0 Release Notes

**发布日期**: 2025-01-04
**版本类型**: Minor Feature Release
**主题**: 全面国际化支持 (Comprehensive i18n Support)

---

## 🌍 核心更新

### 全面国际化 (Internationalization)

RealConsole v1.24.0 实现了完整的中英文国际化支持，涵盖 Web UI、CLI 界面和 Agent LLM 提示词系统。

**支持范围**:
- ✅ Web 界面 (35 keys)
- ✅ CLI 界面 (275 keys)
- ✅ LLM 主对话提示词 (P0)
- ✅ Intent DSL 意图理解提示词 (P1)

**使用方式**:
```bash
# 启动中文版（默认）
realconsole

# 启动英文版
realconsole --lang en-US

# Web 模式
realconsole web --lang en-US
```

## 🔧 技术改进

### 1. YAML 解析器升级
- **从**: `serde_yml` (C-based libyml, 有内存限制)
- **到**: `serde_yaml_ng 0.10` (纯 Rust, 无限制, 社区维护)
- **原因**: 解决大文件解析限制，提升稳定性

### 2. 多文件加载策略
实现三层文件加载机制：
```
Base (Web) → CLI → Prompts
```
- 每个文件独立管理，便于维护
- 避免单文件过大

### 3. 代码优化
**修改文件** (5 个核心文件):
- `src/i18n.rs` - 3 层文件加载实现
- `src/services/llm_service.rs` - P0 提示词 i18n
- `src/commands/llm_prompt_cmd.rs` - `/show-prompt` 命令 i18n
- `src/dsl/intent/llm_bridge.rs` - Intent 提示词 i18n (删除 184 行硬编码)
- `Cargo.toml` - 依赖更新

## 🎯 设计理念

### 三级提示词优先级
```
Runtime (动态设置) > Config (配置文件) > i18n (默认翻译)
```

### 中文优先，英文同步
- 日常开发优先更新中文版
- 大版本发布前同步英文版
- 满足更广泛的英语用户群体
