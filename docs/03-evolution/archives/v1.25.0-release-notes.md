# RealConsole v1.25.0 Release Notes

> **发布日期**: 2025-01-05
> **版本主题**: Markdown 美化渲染 - Claude Code 风格的优雅输出

---

## 🎨 核心特性

### Markdown 渲染系统

RealConsole v1.25.0 引入了全新的 Markdown 渲染系统，让 LLM 输出更加美观、易读。

**主要特点**:
- ✨ **优雅专业**: 参考 Claude Code 品牌配色
- 💚 **护眼舒适**: 柔和配色，长时间使用不疲劳
- 🎨 **主题一致**: 单一主题色贯穿设计
- 📊 **层次分明**: 三级强调层次，阅读焦点清晰

### Claude Code 风格配色

精心设计的配色方案，使用 RGB 精确控制：

| 元素 | 颜色 | RGB 值 |
|------|------|--------|
| 标题 | 柔和浅蓝色 | RGB(100, 180, 255) |
| 粗体 | 明亮白色 | RGB(255, 255, 255) |
| 斜体 | 浅灰色 | RGB(180, 180, 180) |
| 代码块 | 柔和绿色 | RGB(150, 220, 150) |
| 代码块背景 | 深灰色 | RGB(40, 40, 40) |
| 内联代码 | 浅蓝色 | RGB(130, 200, 255) |
| 列表 bullet | 柔和蓝色 | RGB(100, 180, 255) |

**设计亮点**:
- 🎨 主题色（浅蓝色）贯穿标题、内联代码、列表
- 💚 代码块使用柔和绿色 + 深灰背景，护眼舒适
- 📊 粗体（明亮白）→ 斜体（浅灰）形成清晰视觉层次

### 架构优化

正确的实现位置确保了功能的稳定性和全面性：

```
agent.rs (生成) → String → repl.rs (显示/渲染)
                               ↓
                        Markdown 渲染器
                               ↓
                         美化的终端输出
```

**优势**:
- ✅ 统一覆盖所有输出路径（LLM对话、工具调用、Workflow）
- ✅ 支持交互式 REPL 和 `--once` 模式
- ✅ 平滑降级，渲染失败自动回退到纯文本

## 📦 技术实现

### 新增模块

**src/markdown_renderer.rs**:
- 核心 Markdown 渲染逻辑
- 使用 termimad 0.30 库
- 自定义 MadSkin 样式
- 支持流式和一次性渲染

### 修改的文件

1. **src/repl.rs**:
   - 集成 Markdown 渲染器
   - 在输出显示时应用渲染
   - 同时支持 REPL 循环和 run_once 模式

2. **src/config/settings.rs**:
   - 新增 `MarkdownConfig` 结构
   - 支持 `enabled` 和 `render_streaming` 配置

3. **realconsole.yaml**:
   - 新增 `display.markdown` 配置段
   - 默认启用 Markdown 渲染

## 🚀 使用方式

### 配置

在 `realconsole.yaml` 中配置：

```yaml
display:
  markdown:
    enabled: true              # 启用/禁用 Markdown 渲染
    render_streaming: true     # 流式渲染（未来功能）
```

## 🐛 已修复的问题

1. **Markdown 渲染不工作** (#原issue)
   - 根因：渲染位置错误（agent.rs 而非 repl.rs）
   - 修复：移至正确的显示阶段

2. **工具调用路径无渲染**
   - 根因：只处理了流式输出路径
   - 修复：统一在 repl.rs 处理所有路径

3. **逻辑反向错误**
   - 根因：`!render_streaming` 判断导致默认跳过
   - 修复：移除错误逻辑
