## v1.0.0 - v1.3.7 演化历程（2025-10，仅 5 天！）

### v1.3.7 (2025-10-22) - 语音与记忆强化

**主题**: 多模态交互 + 智能记忆管理

**新增功能**:
1. **语音播报系统** - 跨平台 TTS（macOS/Linux/Windows）
   - 异步播报队列，不阻塞主线程
   - 可配置语音、速度、音量
   - 4 个语音命令：`/voice [on|off|status|test]`

2. **Memory 重要性标记** - 三级重要性系统（Normal/Important/Critical）
   - `/memory mark <索引> <级别>` - 标记重要性
   - `/memory important [级别]` - 查看重要记忆
   - 相对时间展示（"5分钟前"、"3小时前"）

3. **Memory 统计分析** - 可视化记忆数据
   - `/memory stats` - 类型分布、时间跨度、进度条可视化

4. **LLM 日志系统** - 记录 LLM 交互（实验性）
   - 自动记录请求/响应
   - Token 统计（初步）

**技术改进**:
- 新增 `voice` 模块（跨平台抽象）
- Memory 数据结构向后兼容（`#[serde(default)]`）
- 完善的测试覆盖（voice + memory）

**相关文档**:
- `CHANGELOG.md` - 详细变更记录

### Phase 4: 工具调用系统 (v0.4.0)

**完成日期**: 2025-10-05（第 3 周）
**实际工期**: 5 天（！）

**核心成果**:
1. ✅ **Tool trait 设计** - 统一的工具接口
2. ✅ **工具注册表** - 动态注册和发现
3. ✅ **Function Calling** - LLM 驱动的工具调用
4. ✅ **内置工具** - 14+ 工具（Shell/文件/时间/搜索等）
5. ✅ **多轮对话** - 最多 5 轮迭代

**工作流程**:
```
用户输入 → LLM 解析（含工具列表）→ 是否需要工具?
              ├─ 否 → 直接返回
              └─ 是 → 执行工具 → 结果返回 LLM → 再次解析 → ...
```

**设计要点**:
- 最多 5 轮迭代（防止无限循环）
- 每轮最多 3 个工具调用
- 工具执行超时控制
- 安全沙箱（工具白名单）
