## 🧪 测试场景

### 场景 1️⃣：拼写纠错基础功能

**测试 1.1 - Cargo 拼写错误**
```bash
# 在 RealConsole 中执行
> !cago build

# 预期结果：
# zsh: command not found: cago
#
# 💡 建议尝试：
#   1. 🔍 cargo build    Did you mean 'cargo'?  (score: 0.93)
#   2. 🔍 cat            Did you mean 'cat'?    (score: ~0.7)
```

**测试 1.2 - Git 拼写错误**
```bash
> !gi status

# 预期结果：
# command not found: gi
#
# 💡 建议尝试：
#   1. 🔍 git            Did you mean 'git'?    (score: 0.85+)
```

**测试 1.3 - npm 拼写错误**
```bash
> !npn --version

# 预期结果：
# 💡 建议尝试：
#   1. 🔍 npm            Did you mean 'npm'?
```

**测试 1.4 - 正确命令（不应有拼写建议）**
```bash
> !ls -la

# 预期结果：
# 正常执行 ls 命令，不应该有拼写建议
```

**验证点**：
- ✅ 拼写错误被正确识别
- ✅ 建议分数合理（距离1的分数 > 0.85）
- ✅ 拼写建议优先于其他建议
- ✅ 正确的命令不会触发拼写建议

---

### 场景 2️⃣：建议缓存过期机制

**测试 2.1 - 生成建议并缓存**
```bash
> /suggest

# 预期结果：显示建议列表
# 💡 建议尝试：
#   1. 🔨 cargo build --release
#   2. 🧪 cargo test
#   3. ...
```

**测试 2.2 - 立即使用缓存（新鲜状态）**
```bash
> 1

# 预期结果：
# ⚡ 执行建议: cargo build --release
# （然后实际执行该命令）
```

**测试 2.3 - 无效的建议编号**
```bash
> 99

# 预期结果：
# ⚠ 无效的建议编号：99
# 提示: 当前有 X 条建议可用
```

**测试 2.4 - 缓存过期测试**
```bash
# 等待 5+ 分钟后（或者重启 RealConsole）

> 1

# 预期结果：
# ⚠ 没有可用的建议
# 原因: Suggestions expired (XXXs ago)
# 提示: 先执行 /suggest 命令查看建议...
```

**验证点**：
- ✅ 建议被正确缓存
- ✅ 数字输入立即执行对应建议
- ✅ 缓存在 5 分钟后自动过期
- ✅ 过期后提供友好的错误提示

### 场景 3️⃣：端到端集成测试

**测试 3.1 - 拼写错误 → 建议 → 快速执行**
```bash
> !cago test

# 步骤 1：拼写错误被检测
# zsh: command not found: cago
#
# 💡 建议尝试：
#   1. 🔍 cargo test    Did you mean 'cargo'?

# 步骤 2：快速执行
> 1

# 步骤 3：命令被执行
# ⚡ 执行建议: cargo test
#    Running unittests src/lib.rs...
```

**测试 3.2 - 错误模式匹配（非拼写错误）**
```bash
# 在一个临时目录中
> cd /tmp/test-dir
> !git status

# 预期结果：
# fatal: not a git repository
#
# 💡 建议尝试：
#   1. 🔀 git init          (错误模式匹配，不是拼写纠错)
#   2. 🔀 git clone <url>
```

**验证点**：
- ✅ 拼写纠错在错误模式之前触发
- ✅ 如果不是拼写错误，使用错误模式匹配
- ✅ 数字快速执行无缝集成
