### 场景 3：验证八卦宫殿存储（代码级）

**目的**: 验证状态能否正确存储到八卦宫殿

由于这是内部功能，需要通过 Rust 代码测试。创建测试文件：

#### 步骤 3.1：创建测试脚本

创建文件 `test_integration.rs`:

```rust
use realconsole::bagua::BaguaMemoryPalace;
use realconsole::liangyyi::{StateTracker, StateTrackerConfig};
use realconsole::liangyyi::taiji::Event;

#[tokio::main]
async fn main() {
    println!("=== v1.10.0 集成测试 ===\n");

    // 1. 创建状态追踪器
    println!("1. 创建状态追踪器...");
    let tracker = StateTracker::new(StateTrackerConfig::default());
    println!("   ✓ 追踪器创建成功\n");

    // 2. 模拟一些事件
    println!("2. 模拟用户活动...");
    for i in 0..5 {
        tracker.update_from_event(Event::UserExecute).await;
        println!("   - 事件 {} 已处理", i + 1);
    }
    println!("   ✓ 5个事件已处理\n");

    // 3. 创建八卦宫殿
    println!("3. 创建八卦宫殿...");
    let mut palace = BaguaMemoryPalace::new();
    println!("   ✓ 八卦宫殿创建成功\n");

    // 4. 同步状态到宫殿
    println!("4. 同步状态到八卦宫殿...");
    match tracker.sync_to_bagua(&mut palace).await {
        Ok(_) => println!("   ✓ 同步成功！"),
        Err(e) => {
            println!("   ✗ 同步失败: {}", e);
            return;
        }
    }
    println!();

    // 5. 验证艮卦（检查点）
    println!("5. 验证艮卦（检查点）...");
    match palace.retrieve(realconsole::bagua::BaguaDimension::Gen, None).await {
        Ok(checkpoints) => {
            println!("   - 检查点数量: {}", checkpoints.len());
            if checkpoints.len() > 0 {
                println!("   ✓ 检查点存储成功");
            } else {
                println!("   ✗ 未找到检查点");
                return;
            }
        }
        Err(e) => {
            println!("   ✗ 读取失败: {}", e);
            return;
        }
    }
    println!();

    // 6. 验证巽卦（趋势）
    println!("6. 验证巽卦（趋势）...");
    match palace.retrieve(realconsole::bagua::BaguaDimension::Xun, None).await {
        Ok(trends) => {
            println!("   - 趋势记录数量: {}", trends.len());
            if trends.len() > 0 {
                println!("   ✓ 趋势存储成功");
            } else {
                println!("   ✗ 未找到趋势记录");
                return;
            }
        }
        Err(e) => {
            println!("   ✗ 读取失败: {}", e);
            return;
        }
    }
    println!();

    // 7. 测试状态恢复
    println!("7. 测试状态恢复...");
    let original = tracker.current_state().await;
    println!("   - 原始阴能量: {:.2}", original.taiji.yin_energy);
    println!("   - 原始阳能量: {:.2}", original.taiji.yang_energy);

    match StateTracker::restore_from_bagua(&palace, StateTrackerConfig::default()).await {
        Ok(restored_tracker) => {
            let restored = restored_tracker.current_state().await;
            println!("   - 恢复阴能量: {:.2}", restored.taiji.yin_energy);
            println!("   - 恢复阳能量: {:.2}", restored.taiji.yang_energy);

            let yin_diff = (original.taiji.yin_energy - restored.taiji.yin_energy).abs();
            let yang_diff = (original.taiji.yang_energy - restored.taiji.yang_energy).abs();

            if yin_diff < 0.01 && yang_diff < 0.01 {
                println!("   ✓ 状态恢复成功（误差 < 0.01）");
            } else {
                println!("   ⚠ 状态恢复有误差");
                println!("     阴能量误差: {:.4}", yin_diff);
                println!("     阳能量误差: {:.4}", yang_diff);
            }
        }
        Err(e) => {
            println!("   ✗ 恢复失败: {}", e);
            return;
        }
    }
    println!();

    // 8. 测试检查点检测
    println!("8. 测试检查点检测...");
    let has_checkpoint = StateTracker::has_checkpoint(&palace).await;
    if has_checkpoint {
        println!("   ✓ 检查点检测正常");
    } else {
        println!("   ✗ 检查点检测失败");
        return;
    }
    println!();

    println!("=== 所有测试通过！✓ ===");
}
```

## 🐛 常见问题排查

### 问题 1：编译失败

**症状**: `cargo build` 报错

**可能原因**:
- Rust 版本过旧（需要 1.70+）
- 依赖未更新

**解决方案**:
```bash
rustup update
cargo clean
cargo build --release
```

### 问题 2：测试失败

**症状**: 某些测试未通过

**排查步骤**:
1. 查看具体失败的测试：
   ```bash
   cargo test --lib liangyyi::tracker::tests -- --nocapture
   ```
2. 检查错误信息
3. 对照预期结果

### 问题 3：状态恢复精度不符

**症状**: 恢复后状态误差 > 0.01

**可能原因**:
- JSON 序列化精度问题
- 浮点数计算误差

**验证方法**:
```rust
println!("原始: {:.10}", original.taiji.yin_energy);
println!("恢复: {:.10}", restored.taiji.yin_energy);
```

如果误差在 0.01-0.05 之间，可以接受（调整测试阈值）

### 问题 4：同步失败

**症状**: sync_to_bagua() 返回错误

**排查步骤**:
1. 检查八卦宫殿是否正确初始化
2. 检查是否有权限问题（如果启用持久化）
3. 查看详细错误信息
