#### ⚠️ 改进建议

**1. 标签去重性能优化**

当前实现：
```rust
pub fn add_tag(&mut self, tag: String) {
    if !self.tags.contains(&tag) {  // O(n) 线性查询
        self.tags.push(tag);
    }
}
```

**问题**: `Vec::contains()` 是 O(n) 操作，批量添加大量标签时性能下降

**优化方案** (当标签数量 > 50 时):
```rust
pub fn add_tags(&mut self, tags: Vec<String>) {
    let existing: HashSet<_> = self.tags.iter().collect();
    for tag in tags {
        if !existing.contains(&tag) {
            self.tags.push(tag);
        }
    }
}
```

**评估**: 对于典型场景（< 10 个标签/条目），当前实现可接受。建议在文档中说明性能特征。

**2. Importance 符号区分性**

当前实现：
```rust
pub fn symbol(&self) -> &'static str {
    match self {
        Importance::Low => "",      // 空字符串
        Importance::Normal => "",   // 空字符串
        Importance::Important => "[*]",
        Importance::Critical => "[**]",
    }
}
```

**问题**: `Low` 和 `Normal` 返回相同符号，展示时无法区分

**建议**:
- 为 `Low` 添加区分符号如 `"[-]"`
- 或在文档中明确说明当前设计意图（低/普通不需要特殊标记）

**2. 类型映射的语义损失** ⚠️

```rust
fn trace_type_to_memory_type(&self, trace_type: &EntryType) -> MemoryEntryType {
    match trace_type {
        EntryType::ContextMessage => MemoryEntryType::User, // 默认映射
        // ...
        _ => MemoryEntryType::System,
    }
}
```

**问题**: `ContextMessage` 可能来自 User 或 Assistant，统一映射为 `User` 会丢失语义

**复现步骤**:
1. 添加 `MemoryEntryType::Assistant` 消息
2. 转换为 `TraceEntry`（变成 `EntryType::ContextMessage`）
3. 通过 `dump()` 读回
4. 转换回 `MemoryEntry` 时变成 `MemoryEntryType::User`

**影响**: 中等 - 数据语义丢失，Assistant 消息被错误标记为 User

**修复方案**:
```rust
fn memory_entry_to_trace(&self, entry: &MemoryEntry) -> TraceEntry {
    let mut trace_entry = TraceEntry::new(/* ... */);

    // 在 metadata 中保存原始类型
    trace_entry.add_metadata(
        "original_memory_type".to_string(),
        serde_json::json!(entry.entry_type.to_string()),
    );

    trace_entry
}

fn trace_to_memory_entry(&self, entry: &TraceEntry) -> MemoryEntry {
    // 优先从 metadata 恢复
    let memory_type = entry
        .get_metadata("original_memory_type")
        .and_then(|v| v.as_str())
        .and_then(|s| MemoryEntryType::from_str(s).ok())
        .unwrap_or_else(|| self.trace_type_to_memory_type(&entry.entry_type));

    // ...
}
```

**3. dump() 容量限制语义不明确**

```rust
pub async fn dump(&self) -> Result<Vec<MemoryEntry>> {
```
