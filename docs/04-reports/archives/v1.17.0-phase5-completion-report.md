## 🎓 技术亮点

### 1. 过滤条件下推设计

采用数据库查询优化中的经典技术，将过滤逻辑从应用层下推到数据访问层：

```rust
pub async fn query_by_dimension_with_filter(
    &self,
    dimension: Dimension,
    limit: usize,
    filter: Option<QueryFilter>,
) -> Result<Vec<TraceEntry>>
```

**优势**:
- 减少无效数据加载
- 提高内存使用效率
- 保持 API 简洁（Optional filter）

### 2. 反向索引架构

采用倒排索引（Inverted Index）设计，实现 O(1) 查询：

```rust
// Tag 索引: tag -> [entry_id1, entry_id2, ...]
HashMap<String, HashSet<Uuid>>

// Importance 索引: importance -> [entry_id1, entry_id2, ...]
HashMap<Importance, HashSet<Uuid>>
```

**特性**:
- 自动维护（在 `add_entry()` 时）
- 自动清理（LRU 淘汰时）
- 线程安全（Arc + RwLock）

### 3. Builder 模式

QueryFilter 使用流式 API，提升可读性：

```rust
let filter = QueryFilter::new()
    .with_entry_type(EntryType::ContextMessage)
    .with_importance(Importance::Important)
    .with_tags(vec!["rust".to_string()]);
```

### 4. 一致性保证

索引与数据的强一致性：
- ✅ add_entry() 时同步更新索引
- ✅ LRU 淘汰时同步清理索引
- ✅ 测试验证一致性（test_index_lru_eviction）
