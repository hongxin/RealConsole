## 🎯 核心目标

解决 `/execute` 命令执行后，**用户看不到任务实际输出结果**的问题。

---

## 📊 问题背景

### 用户场景

```bash
# 用户执行计划
/plan 先计算1加到100，然后再计算将刚才的所得结果与50相乘

# 计划生成（正常）
▸ 3 阶段 · 3 任务 · 15秒
├─ → Stage 1 (5s)
│  └─ 计算1到100的和 $ SUM=$(seq 1 100 | awk '{sum+=$1} END {print sum}') && echo "1到100的和是: $SUM"
├─ → Stage 2 (5s)
│  └─ 将和与50相乘 $ RESULT=$((5050 * 50)) && echo "最终结果是: $RESULT"
└─ → Stage 3 (5s)
   └─ 验证计算结果 $ echo "验证: 5050 × 50 = 252500"

# 执行任务
/execute

# ❌ 当前显示（问题）
✓ 3/3 · 100%

# ✅ 期望显示（应该有输出）
✓ 3/3 · 100%

📋 执行结果:
  ├─ ✓ 计算1到100的和
  │  └─ 输出: 1到100的和是: 5050
  ├─ ✓ 将和与50相乘
  │  └─ 输出: 最终结果是: 252500
  └─ ✓ 验证计算结果
     └─ 输出: 验证: 5050 × 50 = 252500
```

### 根本原因

**数据存储**：✅ 输出已保存

## 🔧 解决方案

### 方案 A: 增强 Standard 模式（推荐）⭐

**思路**: 改进 Standard 模式，**总是显示任务输出**（无论成功或失败）

**优势**:
- ✅ 不破坏现有行为
- ✅ 用户友好（默认就能看到输出）
- ✅ 符合直觉（执行了就该看到结果）

**实现**:
```rust
// Standard 模式新逻辑
println!("\n{} {} · {} · {}秒", status_icon, "3/3", "100%", time);

// 显示所有任务的输出（不只是失败的）
for task_result in &result.task_results {
    let icon = match task_result.status {
        TaskStatus::Success => "✓".green(),
        TaskStatus::Failed => "✗".red(),
        TaskStatus::Skipped => "⊘".yellow(),
        _ => "•".dimmed(),
    };

    println!("  {} {}", icon, task_result.task.name);

    // ✨ 关键改进：总是显示输出
    if !task_result.output.trim().is_empty() {
        for line in task_result.output.lines() {
            println!("    {}", line.dimmed());
        }
    }

    // 失败时额外显示错误
    if let Some(error) = &task_result.error {
        println!("    {} {}", "错误:".red(), error);
    }
}
```

**效果预览**:
```
✓ 3/3 · 100% · 12秒

  ✓ 计算1到100的和
    1到100的和是: 5050
  ✓ 将和与50相乘
    最终结果是: 252500
  ✓ 验证计算结果
    验证: 5050 × 50 = 252500
```

### 方案 B: 新增 Results 模式

**思路**: 引入新的显示模式 `DisplayMode::Results`

**优势**:
- ✅ 更灵活的控制
- ✅ 可以有更丰富的格式

**劣势**:
- ❌ 需要用户手动配置
- ❌ 增加复杂度

**实现**:
```rust
pub enum DisplayMode {
    Minimal,   // ✓ 3/3 · 100%
    Standard,  // 摘要 + 失败详情
    Results,   // ✨ 新增：摘要 + 所有任务输出
    Debug,     // 完整信息
}
```

### 方案 C: 配置选项控制

**思路**: 添加配置项 `show_task_output: bool`

```yaml
# realconsole.yaml
task:
  show_task_output: true  # 默认显示任务输出
  max_output_lines: 50    # 限制输出行数（防止刷屏）
```
