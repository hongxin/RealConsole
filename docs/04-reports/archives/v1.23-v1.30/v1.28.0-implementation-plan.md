# v1.28.0 实施计划：对话回合可视化

**日期**: 2025-11-06
**版本**: v1.28.0
**目标**: 在不改变交互方式的前提下，建立"回合"概念，为 Cell 模型做准备

---

## 🎯 核心目标

### 用户视角
- 看到明确的对话回合边界（卡片式设计）
- 了解每个回合的执行状态和元数据
- 可以折叠/展开历史回合（减少视觉干扰）

### 技术视角
- 建立 ConversationRound 数据结构（Round ≈ Cell）
- 实现回合级别的渲染和状态管理
- 为后续 Cell 独立执行打基础

### 1. 数据结构设计

#### ConversationRound（服务端）

```rust
// src/web/session.rs

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ConversationRound {
    /// 回合 ID
    pub id: String,  // round-{uuid}

    /// 回合序号（从 1 开始）
    pub index: usize,

    /// 用户输入
    pub user_input: String,

    /// AI 响应（完整文本）
    pub ai_response: String,

    /// 使用的工具列表
    pub tools_used: Vec<String>,

    /// 执行时间（秒）
    pub execution_time: f64,

    /// 执行状态
    pub status: RoundStatus,

    /// 创建时间
    pub timestamp: DateTime<Utc>,

    /// 使用的模型
    pub model: String,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub enum RoundStatus {
    /// 等待执行
    Pending,

    /// 执行中
    Running,

    /// 执行成功
    Success,

    /// 执行失败
    Error {
        message: String,
    },
}
```

#### Session 扩展

```rust
// src/web/session.rs

pub struct Session {
    pub id: SessionId,
    pub agent: Arc<RwLock<Agent>>,
    pub created_at: chrono::DateTime<chrono::Utc>,
    pub llm_init_error: Option<String>,
    pub conversation_id: String,

    /// 新增：对话回合列表
    pub rounds: Arc<RwLock<Vec<ConversationRound>>>,
}

impl Session {
    pub fn new(config: Config, registry: CommandRegistry) -> Self {
        // ... 现有逻辑 ...

        Self {
            // ... 现有字段 ...
            rounds: Arc::new(RwLock::new(Vec::new())),
        }
    }

    /// 添加新回合
    pub async fn add_round(&self, round: ConversationRound) {
        let mut rounds = self.rounds.write().await;
        rounds.push(round);
    }

    /// 更新回合状态
    pub async fn update_round_status(&self, round_id: &str, status: RoundStatus) {
        let mut rounds = self.rounds.write().await;
        if let Some(round) = rounds.iter_mut().find(|r| r.id == round_id) {
            round.status = status;
        }
    }

    /// 完成回合（更新响应和执行时间）
    pub async fn complete_round(
        &self,
        round_id: &str,
        response: String,
        execution_time: f64,
        tools_used: Vec<String>,
    ) {
        let mut rounds = self.rounds.write().await;
        if let Some(round) = rounds.iter_mut().find(|r| r.id == round_id) {
            round.ai_response = response;
            round.execution_time = execution_time;
            round.tools_used = tools_used;
            round.status = RoundStatus::Success;
        }
    }
}
```

### 4. JavaScript 实现

#### Terminal 类扩展

```javascript
class Terminal {
    constructor() {
        // ... 现有属性 ...

        this.rounds = [];  // 回合列表
        this.currentRound = null;  // 当前执行的回合
    }

    // 创建新回合
    createRound(roundData) {
        const round = {
            id: roundData.id,
            index: roundData.index,
            userInput: roundData.user_input,
            aiResponse: '',
            toolsUsed: [],
            executionTime: 0,
            status: roundData.status,
            timestamp: roundData.timestamp,
            model: roundData.model,
            element: null,
            expanded: true,
        };

        // 创建 DOM 元素
        round.element = this.createRoundElement(round);
        this.outputArea.appendChild(round.element);

        this.rounds.push(round);
        this.currentRound = round;

        return round;
    }

    // 创建回合 DOM 元素
    createRoundElement(round) {
        const roundDiv = document.createElement('div');
        roundDiv.className = 'conversation-round expanded';
        roundDiv.dataset.roundId = round.id;

        // 头部
        const header = document.createElement('div');
        header.className = 'round-header';

        const info = document.createElement('div');
        info.className = 'round-info';
        info.innerHTML = `
            <span class="round-number">Round #${round.index}</span>
            <span class="round-status ${round.status.toLowerCase()}">${this.getStatusIcon(round.status)}</span>
            <span class="round-time">${round.executionTime.toFixed(2)}s</span>
            <span class="round-tools">${this.renderTools(round.toolsUsed)}</span>
            <span class="round-summary">${this.truncate(round.userInput, 50)}</span>
        `;

        const toggleBtn = document.createElement('button');
        toggleBtn.className = 'round-toggle';
        toggleBtn.textContent = '▼';
        toggleBtn.onclick = () => this.toggleRound(round.id);

        header.appendChild(info);
        header.appendChild(toggleBtn);

        // 内容
        const content = document.createElement('div');
        content.className = 'round-content';

        // 用户输入
        const input = document.createElement('div');
        input.className = 'round-input';
        input.innerHTML = `
            <span class="prompt">% </span>
            <span class="input-text">${this.escapeHtml(round.userInput)}</span>
        `;

        // AI 输出
        const output = document.createElement('div');
        output.className = 'round-output';
        output.innerHTML = '<div class="output-content"></div>';

        content.appendChild(input);
        content.appendChild(output);

        roundDiv.appendChild(header);
        roundDiv.appendChild(content);

        return roundDiv;
    }

    // 更新回合状态
    updateRoundStatus(roundId, status) {
        const round = this.rounds.find(r => r.id === roundId);
        if (!round) return;

        round.status = status;
        const statusSpan = round.element.querySelector('.round-status');
        statusSpan.textContent = this.getStatusIcon(status);
        statusSpan.className = `round-status ${status.toLowerCase()}`;
    }

    // 完成回合
    completeRound(roundData) {
        const round = this.rounds.find(r => r.id === roundData.id);
        if (!round) return;

        round.aiResponse = roundData.ai_response;
        round.executionTime = roundData.execution_time;
        round.toolsUsed = roundData.tools_used;
        round.status = roundData.status;

        // 更新 UI
        const statusSpan = round.element.querySelector('.round-status');
        statusSpan.textContent = this.getStatusIcon(roundData.status);
        statusSpan.className = `round-status ${roundData.status.toLowerCase()}`;

        const timeSpan = round.element.querySelector('.round-time');
        timeSpan.textContent = `${roundData.execution_time.toFixed(2)}s`;

        const toolsSpan = round.element.querySelector('.round-tools');
        toolsSpan.innerHTML = this.renderTools(roundData.tools_used);

        const outputContent = round.element.querySelector('.output-content');
        outputContent.innerHTML = this.renderMarkdown(roundData.ai_response);
    }

    // 折叠/展开回合
    toggleRound(roundId) {
        const round = this.rounds.find(r => r.id === roundId);
        if (!round) return;

        round.expanded = !round.expanded;
        round.element.classList.toggle('collapsed');
        round.element.classList.toggle('expanded');

        const toggleBtn = round.element.querySelector('.round-toggle');
        toggleBtn.textContent = round.expanded ? '▼' : '▶';
    }

    // 工具方法
    getStatusIcon(status) {
        const icons = {
            success: '✓',
            running: '⏳',
            error: '✗',
            pending: '⏸',
        };
        return icons[status.toLowerCase()] || '?';
    }

    renderTools(tools) {
        if (!tools || tools.length === 0) return '';
        return tools.map(tool =>
            `<span class="tool-badge">${tool}</span>`
        ).join('');
    }

    truncate(text, maxLength) {
        if (text.length <= maxLength) return text;
        return text.substring(0, maxLength) + '...';
    }

    escapeHtml(text) {
        const div = document.createElement('div');
        div.textContent = text;
        return div.innerHTML;
    }
}
```

#### WebSocket 消息处理

```javascript
handleMessage(data) {
    switch (data.type) {
        case 'round_start':
            this.createRound(data.round);
            break;

        case 'round_update':
            this.updateRoundStatus(data.round_id, data.status);
            break;

        case 'round_complete':
            this.completeRound(data.round);
            this.scrollToBottom();
            break;

        case 'round_history':
            // 加载历史回合（重连时）
            data.rounds.forEach(round => {
                this.createRound(round);
                this.completeRound(round);
            });
            break;

        case 'thinking':
            // 现有逻辑，但现在在当前回合中显示
            if (this.currentRound) {
                const outputContent = this.currentRound.element.querySelector('.output-content');
                outputContent.innerHTML = `<div class="thinking">🤔 思考中（${data.model}）...</div>`;
            }
            break;

        case 'stream':
            // 现有流式输出逻辑
            if (this.currentRound) {
                const outputContent = this.currentRound.element.querySelector('.output-content');
                this.streamBuffer += data.content;
                outputContent.innerHTML = this.renderMarkdown(this.streamBuffer);
            }
            break;

        // ... 其他消息类型 ...
    }
}
```
