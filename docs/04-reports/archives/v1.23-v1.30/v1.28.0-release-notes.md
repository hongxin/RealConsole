# RealConsole v1.28.0 发布说明

**发布日期**: 2025-11-07
**版本**: v1.28.0
**代号**: "对话回合可视化"

---

## 🎯 版本概述

v1.28.0 是 RealConsole v1 → v2 过渡计划的第一个版本，引入了 **Jupyter-like 对话回合可视化**功能，为未来的 Cell 执行模型和 Notebook 体验奠定基础。

这是一个**重要的功能性版本**，将 Web 终端从简单的流式输出升级为结构化的回合卡片视图，同时保留传统模式供用户选择。

---

## ✨ 核心功能

### 1. 对话回合可视化 ⭐

**Jupyter-like 卡片式回合显示**：
- 每个对话轮次显示为独立的回合卡片
- 包含完整的元数据（状态、执行时间、工具使用、模型）
- 支持折叠/展开历史回合
- 赛博朋克主题风格，与整体 UI 一致

**回合数据结构**：
```rust
pub struct ConversationRound {
    pub id: String,              // 唯一 ID
    pub index: usize,            // 回合序号
    pub user_input: String,      // 用户输入
    pub ai_response: String,     // AI 响应
    pub tools_used: Vec<String>, // 使用的工具
    pub execution_time: f64,     // 执行时间（秒）
    pub status: RoundStatus,     // 状态（Pending/Running/Success/Error）
    pub timestamp: DateTime<Utc>,
    pub model: String,           // 模型名称
}
```

**视觉效果**：
```
┌────────────────────────────────────────────┐
│ Round #1  ✓  1.23s  [Tool1]  hello...    ▼│ ← 回合头部
├────────────────────────────────────────────┤
│ 📥 Input:                                  │
│ ┃ hello                                    │
│                                            │
│ 📤 Output:                                 │
│ ┃ Hello! I'm RealConsole...               │ ← Markdown 渲染
└────────────────────────────────────────────┘
```

### 2. 视图模式切换 🔄

**双模式支持**：
- **📊 回合模式**（默认）: 卡片式结构化显示
- **📜 传统模式**: 流式输出，简洁连续

**切换方式**：
- 页面右上角切换按钮
- 即时切换，零数据丢失
- 历史数据完整保留

**设计理念**：
- 保留用户选择权
- 适应不同使用场景
- 为高级用户提供灵活性

### 3. 执行反馈优化 ⚡

**回合模式飞轮动画**：
- 状态图标显示旋转飞轮（⠋⠙⠹⠸⠼⠴⠦⠧⠇⠏）
- 时间区域显示模型名称和"思考中..."
- 完成后自动恢复为状态图标和执行时间

**视觉反馈**：
```
执行前: Round #1  ⏳  0.00s  hello...  ▼
执行中: Round #1  ⠋  deepseek-chat 思考中...  ▼  ← 飞轮旋转
执行后: Round #1  ✓  1.23s  [Tool1]  hello...  ▼
```

## 🐛 Bug 修复

### 修复 1: 状态图标显示问题
- **问题**: Rust enum 序列化格式不一致导致状态图标显示 `?`
- **原因**: `RoundStatus::Error` 序列化为对象 `{"error": {...}}`
- **修复**: 添加 `normalizeStatus()` 方法统一处理
- **影响文件**: `src/web/server.rs` (+13 行)

### 修复 2: 输入输出格式问题
- **问题**: HTML 结构与 CSS 样式不匹配
- **原因**: 使用了错误的 class 名称
- **修复**: 更新 HTML 结构使用正确的 class
- **影响文件**: `src/web/server.rs` (2 处修改)

### 修复 3: 传统模式重复输出
- **问题**: 切换到传统模式后出现内容重复
- **原因**: `createRound()` 创建的元素默认可见
- **修复**: 根据视图模式设置初始显示状态
- **影响文件**: `src/web/server.rs` (+5 行)

### 修复 4: 欢迎消息不显示
- **问题**: 回合模式下欢迎消息被跳过
- **原因**: `writePlainText()` 无条件跳过
- **修复**: 添加系统消息标志参数
- **影响文件**: `src/web/server.rs` (+4 行)

## 🚀 升级指南

### 从 v1.27.0 升级

**无需任何配置更改**，直接使用新版本即可：

```bash
# 1. 拉取最新代码
git pull origin main

# 2. 重新编译
cargo build --release

# 3. 启动 Web 服务
export DEEPSEEK_API_KEY="your-api-key"
./target/release/realconsole web

# 4. 浏览器访问
http://127.0.0.1:7788
```

**默认行为**：
- Web 终端使用**回合模式**
- CLI 版本保持不变
- 所有配置向后兼容

### 配置建议

**无需额外配置**，但可以考虑：
- 使用真实的 API Key（不是 "test-key"）
- 配置合适的模型（deepseek-chat 或其他）

## 📋 已知限制

1. **历史持久化**:
   - 当前回合历史仅保存在内存
   - 服务器重启后历史丢失
   - **计划**: v1.30.0 实现 SQLite 持久化

2. **视图偏好**:
   - 视图模式选择不持久化
   - 每次刷新恢复默认（回合模式）
   - **计划**: v1.29.0 使用 localStorage 保存

3. **工具提取**:
   - 依赖 LLM 响应的 `__DEBUG__` 格式
   - 格式变化可能导致提取失败
   - **计划**: 更鲁棒的解析逻辑

4. **回合编辑**:
   - 当前不支持修改历史回合
   - **计划**: v1.31.0 的 Cell 模型支持
