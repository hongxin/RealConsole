## 用户反馈

测试过程中发现两个问题：

1. **回合模式缺少执行反馈** - 当大模型运行时没有视觉反馈，用户不知道系统在工作
2. **传统模式重复输出bug** - 切换到传统模式后，回合模式的内容重复显示

## 修复1：回合模式飞轮动画

### 问题描述

在回合模式下，当用户输入命令后，LLM 开始处理，但没有任何视觉反馈：
- 回合卡片显示为 `⏳` 状态图标
- 但没有动画或提示文字
- 用户不知道模型是否在运行，也不知道使用的是哪个模型

### 解决方案

**在回合卡片的状态区域添加飞轮动画**：

#### JavaScript 改进
```javascript
writeSpinner(modelName = '') {
    // 回合模式下在当前回合卡片中显示 Spinner
    if (this.viewMode === 'round') {
        if (this.currentRound && this.currentRound.element) {
            const statusSpan = this.currentRound.element.querySelector('.round-status');
            if (statusSpan) {
                // 添加飞轮动画类
                statusSpan.classList.add('spinner-active');
                // 显示模型名称（如果有）
                const timeSpan = this.currentRound.element.querySelector('.round-time');
                if (timeSpan && modelName) {
                    timeSpan.textContent = `${modelName} 思考中...`;
                }
            }
        }
        return;
    }
    // ... 传统模式逻辑
}
```

#### CSS 动画
```css
/* 飞轮动画（回合模式思考中） */
.round-status.spinner-active::before {
    content: '⠋';
    display: inline-block;
    animation: spinner-rotate 1s steps(10) infinite;
}

@keyframes spinner-rotate {
    0% { content: '⠋'; }
    10% { content: '⠙'; }
    20% { content: '⠹'; }
    30% { content: '⠸'; }
    40% { content: '⠼'; }
    50% { content: '⠴'; }
    60% { content: '⠦'; }
    70% { content: '⠧'; }
    80% { content: '⠇'; }
    90% { content: '⠏'; }
    100% { content: '⠋'; }
}
```

### 视觉效果

**执行前**:
```
Round #1  ⏳  0.00s  hello...  ▼
```

**执行中**（飞轮动画旋转）:
```
Round #1  ⠋  deepseek-chat 思考中...  hello...  ▼
```

**执行后**:
```
Round #1  ✓  1.23s  [Tool1] [Tool2]  hello...  ▼
```

### 技术细节

1. **飞轮字符**: 使用 Braille patterns (`⠋⠙⠹⠸⠼⠴⠦⠧⠇⠏`)
2. **动画方式**: CSS `@keyframes` + `content` 属性
3. **停止动画**: `completeRound()` 时重置 `className`，自动移除 `spinner-active`

## 修复2：传统模式重复输出

### 问题描述

切换到传统模式后：
- 回合卡片仍然显示
- 传统输出也显示
- 导致内容重复

### 根本原因

`applyViewMode()` 方法的逻辑问题：
- 回合卡片元素没有被添加到 `this.lines` 数组
- 使用 `this.lines.forEach` 无法正确隐藏回合卡片
- 需要直接查询 DOM 元素

### 解决方案

**改进 `applyViewMode()` 方法**：

#### 修复前（错误）
```javascript
applyViewMode() {
    if (this.viewMode === 'round') {
        this.lines.forEach(line => {
            if (!line.classList.contains('conversation-round')) {
                line.style.display = 'none';
            }
        });
        // ...
    }
}
```

问题：`this.lines` 不包含回合卡片元素

#### 修复后（正确）
```javascript
applyViewMode() {
    if (this.viewMode === 'round') {
        // 回合模式：隐藏传统输出，显示回合卡片

        // 隐藏所有传统输出行
        this.lines.forEach(line => {
            line.style.display = 'none';
        });

        // 显示所有回合卡片
        const roundElements = this.outputArea.querySelectorAll('.conversation-round');
        roundElements.forEach(el => {
            el.style.display = 'block';
        });
    } else {
        // 传统模式：显示传统输出，隐藏回合卡片

        // 隐藏所有回合卡片
        const roundElements = this.outputArea.querySelectorAll('.conversation-round');
        roundElements.forEach(el => {
            el.style.display = 'none';
        });

        // 显示所有传统输出行
        this.lines.forEach(line => {
            line.style.display = 'block';
        });
    }
}
```

### 关键改进

1. **使用 DOM 查询**: `querySelectorAll('.conversation-round')` 直接查找所有回合卡片
2. **明确的显示/隐藏**: 分别处理传统输出和回合卡片
3. **顺序优化**: 先隐藏不需要的，再显示需要的

## 测试验证

### 测试步骤

```bash
# 1. 使用真实 API Key
export DEEPSEEK_API_KEY="sk-your-real-api-key-here"

# 2. 启动服务
./target/release/realconsole web

# 3. 浏览器访问
http://127.0.0.1:7788
```

### 验证要点

#### ✅ 飞轮动画测试

1. **回合模式下输入命令**:
   - 输入: `hello`
   - 观察: 状态图标显示旋转的飞轮（⠋⠙⠹...）
   - 时间显示: `deepseek-chat 思考中...`
   - 完成后: 飞轮停止，显示 ✓ 和执行时间

2. **传统模式下输入命令**:
   - 切换到传统模式
   - 输入: `hello`
   - 观察: 显示传统的飞轮动画（在独立行）

#### ✅ 视图切换测试

1. **默认回合模式**:
   - 页面加载显示欢迎消息
   - 输入命令显示回合卡片
   - 无传统输出

2. **切换到传统模式**:
   - 点击 `📊 回合模式` 按钮
   - 按钮变为 `📜 传统模式`
   - 回合卡片消失
   - 显示传统流式输出（包括历史）
   - **无重复内容**

3. **切换回回合模式**:
   - 再次点击按钮
   - 按钮恢复为 `📊 回合模式`
   - 传统输出消失
   - 回合卡片显示（包括历史）
   - **无重复内容**
