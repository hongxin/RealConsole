## 功能概述

为解决**输出重复**问题（回合卡片和传统流式输出同时显示），实现了**视图模式切换**功能，允许用户在两种显示模式之间自由切换：

### 两种视图模式

#### 1. 📊 回合模式（默认）
- **Jupyter-like 卡片式显示**
- 每个对话回合显示为独立卡片
- 包含元数据（状态、时间、工具）
- 支持折叠/展开历史回合
- 适合结构化查看和诊断

**视觉效果**:
```
┌─────────────────────────────────────────┐
│ Round #1  ✓  1.23s  [Tool]  hello...  ▼│
├─────────────────────────────────────────┤
│ 📥 Input:                               │
│ ┃ hello                                 │
│                                         │
│ 📤 Output:                              │
│ ┃ Hello! I'm RealConsole...            │
└─────────────────────────────────────────┘
```

#### 2. 📜 传统模式
- **流式输出显示**（v1.27.0 风格）
- 命令和输出按时间顺序线性排列
- 简洁、连续的终端体验
- 适合快速浏览和复制输出

**视觉效果**:
```
% hello
Hello! I'm RealConsole...

% help
Available commands:
...
```

## 实施细节

### 1. 核心机制

**模式标志**:
```javascript
this.viewMode = 'round';  // 'round' 或 'stream'
```

**输出方法修改**:
```javascript
writeCommand(command) {
    // 回合模式下跳过（已在回合卡片中显示）
    if (this.viewMode === 'round') return;
    // ... 原有逻辑
}

writeOutput(content) {
    // 回合模式下跳过（已在回合卡片中显示）
    if (this.viewMode === 'round') return;
    // ... 原有逻辑
}
```

**模式切换逻辑**:
```javascript
toggleViewMode() {
    this.viewMode = this.viewMode === 'round' ? 'stream' : 'round';
    this.applyViewMode();  // 应用显示/隐藏
}

applyViewMode() {
    if (this.viewMode === 'round') {
        // 隐藏传统输出行，显示回合卡片
        this.lines.forEach(line => {
            if (!line.classList.contains('conversation-round')) {
                line.style.display = 'none';
            }
        });
        this.rounds.forEach(round => {
            if (round.element) {
                round.element.style.display = 'block';
            }
        });
    } else {
        // 显示传统输出行，隐藏回合卡片
        this.lines.forEach(line => {
            if (!line.classList.contains('conversation-round')) {
                line.style.display = 'block';
            }
        });
        this.rounds.forEach(round => {
            if (round.element) {
                round.element.style.display = 'none';
            }
        });
    }
}
```

## 技术亮点

### 1. 零数据丢失
- 两种模式共享同一套数据（`this.lines` 和 `this.rounds`）
- 切换模式时只改变 `display` 属性，不删除 DOM 元素
- 历史数据完整保留

### 2. 高性能切换
- 使用 CSS `display` 属性切换可见性
- 无需重新渲染或重新创建元素
- 切换操作即时响应

### 3. 智能输出控制
- 在输出方法层面拦截（`writeCommand`, `writeOutput`, `writeSpinner`）
- 回合模式下直接 `return`，避免创建不必要的 DOM 元素
- 减少内存占用和渲染开销

### 4. 一致的用户体验
- 按钮文字动态更新（"回合模式" ↔ "传统模式"）
- Tooltip 提示下一步操作（"切换到传统流式输出" ↔ "切换到回合卡片视图"）
- 粉色主题与工具徽章保持一致

## 用户建议来源

此功能是根据用户反馈实施的：

> "与原有输出有重复，我刚才测试结果附在后面。建议改成一种状态切换来作为解决方案，老的这种输出方式保留，但是可选（默认缺省）切换为现有的折叠式输出，这样的话用户可以获得一致体验，也可以保留老的简洁输出内容。"

**实施原则**:
1. ✅ 保留两种输出方式
2. ✅ 提供状态切换机制
3. ✅ 默认使用回合模式（新功能）
4. ✅ 用户可切换回传统模式（老功能）
5. ✅ 两种模式互不干扰
