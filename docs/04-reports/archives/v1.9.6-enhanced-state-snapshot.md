# v1.9.6 开发报告：增强状态快照

**日期**: 2025-10-28
**版本**: v1.9.6
**类型**: 功能增强

## 📋 概述

本版本扩展了两仪（Liangyyi）系统的状态追踪能力，为太极（Taiji）添加了上下文强度和持续时间维度，为状态快照（StateSnapshot）增加了四个观测维度，为后续多维状态空间演化奠定基础。

## ✨ 核心变更

### 1. 扩展 Taiji 结构 (src/liangyyi/taiji.rs)

#### 新增字段

```rust
/// ✨ v1.9.6: 上下文强度（0.0-1.0）
///
/// 表示当前上下文的强度：
/// - 0.0: 弱上下文（刚开始、不确定）
/// - 0.5: 中等上下文
/// - 1.0: 强上下文（深度投入、确定性高）
pub context_intensity: f64,

/// ✨ v1.9.6: 上下文持续时间
///
/// 记录当前上下文已经持续的时间
/// 用于分析状态稳定性和转换周期
pub context_duration: Duration,
```

#### 新增方法

**构造函数**:
```rust
pub fn with_context_and_intensity(context: TaijiContext, intensity: f64) -> Self
```
创建指定上下文和强度的太极实例，强度自动限制在 [0.0, 1.0] 范围。

**上下文管理**:
```rust
pub fn switch_context(&mut self, new_context: TaijiContext)
```
切换到新上下文时，重置持续时间为零，强度重置为 0.3（新上下文从较低强度开始）。

```rust
pub fn enhance_context(&mut self, delta: f64)
```
增强或减弱上下文强度（支持正负 delta），结果自动限制在 [0.0, 1.0] 范围。

**自动追踪**:
`update_from_event()` 方法现在会：
- 自动计算时间差并更新 `context_duration`
- 根据持续时间自动增强上下文强度（每分钟最多增强 0.1）
- 空闲时衰减上下文强度（每次 -0.02）

#### 设计理念

体现"一分为三"哲学中的**连续性**思想：
- 上下文不是离散的"强/弱"二态，而是 0.0-1.0 的连续谱
- 时间维度引入动态演化：上下文会随时间自然增强或衰减
- 为后续多维状态空间（v1.11.0 StateVector）打基础

### 2. 增强 StateSnapshot 结构 (src/liangyyi/tracker.rs)

#### 新增观测维度

```rust
pub struct StateSnapshot {
    pub taiji: Taiji,
    pub liangyyi: Liangyyi,
    pub sixiang: Sixiang,
    pub timestamp: DateTime<Utc>,

    // ✨ v1.9.6: 四个新增观测维度
    pub user_activity_level: f64,   // 基于 yang_energy
    pub system_load: f64,            // 基于 context_intensity
    pub learning_efficiency: f64,    // 基于 balance()
    pub decision_confidence: f64,    // 基于 balance()
}
```

#### 智能构造函数

```rust
pub fn from_current_state(taiji: Taiji, liangyyi: Liangyyi, sixiang: Sixiang) -> Self {
    let user_activity_level = taiji.yang_energy;
    let system_load = taiji.context_intensity;
    let learning_efficiency = taiji.balance();
    let decision_confidence = taiji.balance();

    Self {
        taiji, liangyyi, sixiang,
        timestamp: Utc::now(),
        user_activity_level,
        system_load,
        learning_efficiency,
        decision_confidence,
    }
}
```

**自动计算策略**:
- `user_activity_level`: 直接映射 `yang_energy`（阳主动）
- `system_load`: 映射 `context_intensity`（上下文强度反映系统负载）
- `learning_efficiency`: 映射 `balance()`（平衡度高，学习效率高）
- `decision_confidence`: 映射 `balance()`（平衡度高，决策信心强）

#### 新增工具方法

```rust
pub fn overall_score(&self) -> f64 {
    (self.user_activity_level * 0.25
        + self.system_load * 0.25
        + self.learning_efficiency * 0.25
        + self.decision_confidence * 0.25)
        .clamp(0.0, 1.0)
}
```
计算综合评分（四个维度等权重 0.25）。

```rust
pub fn is_optimal(&self) -> bool {
    self.user_activity_level > 0.7
        && self.system_load < 0.8
        && self.learning_efficiency > 0.6
        && self.decision_confidence > 0.6
}
```
判断是否处于最优状态（高活跃、负载不过高、高效率、高信心）。

#### 集成更新

更新了两处使用 StateSnapshot 的地方：

**current_state()**:
```rust
pub async fn current_state(&self) -> StateSnapshot {
    let taiji = self.current_taiji.read().await.clone();
    let sixiang = *self.current_sixiang.read().await;
    let liangyyi = Liangyyi::from_taiji(&taiji);

    StateSnapshot::from_current_state(taiji, liangyyi, sixiang)
}
```

**record_snapshot()**:


## 🎯 设计亮点

### 1. 向后兼容

- 所有现有构造函数保持不变（`new()`, `with_context()`）
- 新字段使用默认值（`context_intensity: 0.5`, `context_duration: Duration::zero()`）
- StateSnapshot 旧代码自动适配新构造函数

### 2. 自动化计算

- 四个观测维度从 Taiji 状态自动派生，无需手动指定
- 时间追踪自动完成，无需显式调用更新
- 强度自动 clamp，防止越界

### 3. 哲学一致性

**体现"一分为三"**:
- 不是"强/弱"二分，而是 [0.0, 1.0] 连续谱
- 不是"活跃/空闲"二分，而是阴阳能量连续变化
- 不是"好/坏"二分，而是四维观测空间

**体现"易"（变化）**:
- context_duration 引入时间维度
- 上下文强度随时间自然演化
- 状态不是静态的，而是动态流动的

### 4. 扩展性

为未来版本预留接口：
- v1.11.0 StateVector: 多维状态空间，可直接使用四个观测维度
- v1.12.0 预测模型: 基于历史 StateSnapshot 预测未来状态
- v1.13.0 自适应系统: 根据 overall_score() 和 is_optimal() 动态调整

## 🚀 使用示例

### 创建带强度的上下文

```rust
let taiji = Taiji::with_context_and_intensity(
    TaijiContext::UserInteraction,
    0.8  // 高强度交互
);
```

### 动态调整上下文强度

```rust
// 用户深度投入，增强上下文
taiji.enhance_context(0.2);

// 用户分心，减弱上下文
taiji.enhance_context(-0.1);
```

### 上下文切换

```rust
// 从用户交互切换到决策阶段
taiji.switch_context(TaijiContext::DecisionMaking);
// 自动重置: intensity = 0.3, duration = 0
```

### 获取增强状态快照

```rust
let snapshot = tracker.current_state().await;

println!("用户活跃度: {:.2}", snapshot.user_activity_level);
println!("系统负载: {:.2}", snapshot.system_load);
println!("学习效率: {:.2}", snapshot.learning_efficiency);
println!("决策信心: {:.2}", snapshot.decision_confidence);
println!("综合评分: {:.2}", snapshot.overall_score());
println!("是否最优: {}", snapshot.is_optimal());
```
