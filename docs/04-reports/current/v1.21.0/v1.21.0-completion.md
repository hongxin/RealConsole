- ✅ 测试数量：1227 → 1230 (+3)

**配置项**:
```yaml

  display:
    show_task_output: true         # 是否显示任务输出
    max_output_lines: 50           # 最大行数，0=不限制
    highlight_numbers: true        # 是否高亮数字
    show_task_duration: true       # 是否显示执行时间
  execution:
    merge_stages: true             # 是否合并 Stage
    max_merged_tasks: 20           # 最大合并任务数
```
