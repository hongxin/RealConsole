**文件**: `src/commands/task_cmd.rs` (lines 78-192)

实现了完整的任务持久化数据结构：

```rust
#[derive(Debug, Clone, serde::Serialize, serde::Deserialize)]
pub struct SavedTask {
    pub id: String,                          // UUID
    pub name: Option<String>,                // 用户自定义名称
    pub created_at: chrono::DateTime<chrono::Utc>,
    pub goal: String,                        // 任务目标
    pub plan: ExecutionPlan,                 // 执行计划
    pub result: Option<ExecutionResult>,     // 执行结果（可选）
}
```

**关键方法**:
- `new()` - 创建新的保存任务（自动生成 UUID）
- `with_name()` - 设置任务名称
- `save_to_file()` - 保存到 JSON 文件（`~/.realconsole/tasks/{timestamp}_{id}.json`）
- `load_from_file()` - 从文件加载
- `list_all()` - 列出所有保存的任务（按创建时间倒序）
- `tasks_dir()` - 获取任务目录路径

## 🔧 技术亮点

### 1. JSON 持久化设计

**文件命名规则**: `{timestamp}_{id}.json`
- `timestamp`: YYYYmmdd_HHMMSS 格式
- `id`: UUID 前 8 位
- 示例: `20251102_103000_a1b2c3d4.json`

**存储位置**: `~/.realconsole/tasks/`
- 跨平台支持（使用 `dirs` crate）
- 自动创建目录
- 按创建时间倒序列出

### 2. 完整的序列化支持

为整个任务类型体系添加了 Serde 支持：
- ExecutionPlan（包含 stages, goal, estimated_time, created_at）
- ExecutionStage（包含 tasks, execution_mode）
- ExecutionMode（枚举：Sequential, Parallel）
- TaskResult（包含 task, status, output, error, timestamps）
- ExecutionResult（包含 task_results, statistics）

### 3. 用户体验设计

**保存输出**:
```
✓ 任务已保存
  名称: my_task
  路径: ~/.realconsole/tasks/20251102_103000_a1b2c3d4.json

使用 /task_list 查看所有保存的任务
```

**列表输出**:
- 紧凑格式，一目了然
- 状态图标区分已执行/未执行
- 目标预览（防止过长）
- 序号方便引用

**加载输出**:
```
✓ 任务已加载
  名称: my_task
  目标: 编译并运行 Rust 项目
  计划: 5 任务
  状态: 已执行

使用 /tasks 查看计划，/execute 执行任务
```

### 4. 错误处理

**完整的错误场景覆盖**:
- 无待保存计划 → 友好提示
- 无效任务 ID → 显示有效范围
- 任务 ID 超出范围 → 提示使用 /task_list
- 文件 I/O 错误 → 显示具体错误信息
- JSON 序列化错误 → anyhow 错误链
