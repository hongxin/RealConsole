# v1.22.1 - Task 命令重构设计

**目标**: 优雅的子命令架构
**优先级**: P1（极简主义 + 易变哲学）
**预计时间**: 2-3 小时

---

## 🎯 设计理念

### 极简主义 (Minimalism)
- **减少顶层命令数量**: 3 个命令合并为 1 个
- **清晰的命名空间**: `/task` 统一管理所有任务操作
- **直观的用户体验**: 符合 Unix 风格（如 `git add`, `docker run`）

### 易变哲学 (Flexibility)
- **易于扩展**: 新增子命令无需修改核心架构
- **职责分离**: 每个子命令独立处理逻辑
- **代码优雅**: 使用 Rust 枚举和模式匹配

---

## 📋 命令架构对比

### 当前设计 (v1.22.0)

```bash
/task_save [name]      # 保存任务
/task_list             # 列出任务
/task_load <id>        # 加载任务
```

**问题**:
- ❌ 占用 3 个顶层命令
- ❌ 命名冗长（task_ 前缀）
- ❌ 不易扩展（未来功能需要新增更多 /task_* 命令）
- ❌ 缺乏层次感

### 新设计 (v1.22.1)

```bash
/task <subcommand> [args]

Subcommands:
  save [name]      保存当前任务（可选命名）
  list             列出所有保存的任务
  load <id>        加载任务到当前会话
  show             显示当前任务详情（等同于 /tasks）
  delete <id>      删除保存的任务（新增）
  help             显示帮助信息
```

**优势**:
- ✅ 只占用 1 个顶层命令
- ✅ 清晰的命名空间
- ✅ 易于扩展（未来可添加 export, import 等）
- ✅ 符合用户习惯（类似 git, docker）
- ✅ 自带 help 子命令

### 1. TaskSubcommand 枚举

```rust
/// 任务管理子命令
#[derive(Debug, Clone, PartialEq)]
pub enum TaskSubcommand {
    /// 保存当前任务
    Save { name: Option<String> },

    /// 列出所有保存的任务
    List,

    /// 加载任务
    Load { id: usize },

    /// 显示当前任务详情
    Show,

    /// 删除保存的任务
    Delete { id: usize },

    /// 显示帮助
    Help,
}
```

### 2. 优雅的解析函数

```rust
impl TaskSubcommand {
    /// 解析子命令
    pub fn parse(input: &str) -> Result<Self, String> {
        let parts: Vec<&str> = input.trim().split_whitespace().collect();

        if parts.is_empty() {
            return Ok(Self::Help);
        }

        match parts[0] {
            "save" => {
                let name = parts.get(1).map(|s| s.to_string());
                Ok(Self::Save { name })
            }
            "list" => Ok(Self::List),
            "load" => {
                let id = parts.get(1)
                    .ok_or("缺少任务 ID")?
                    .parse()
                    .map_err(|_| "无效的任务 ID")?;
                Ok(Self::Load { id })
            }
            "show" => Ok(Self::Show),
            "delete" => {
                let id = parts.get(1)
                    .ok_or("缺少任务 ID")?
                    .parse()
                    .map_err(|_| "无效的任务 ID")?;
                Ok(Self::Delete { id })
            }
            "help" => Ok(Self::Help),
            cmd => Err(format!("未知子命令: {}", cmd)),
        }
    }
}
```

### 3. 统一的命令处理

```rust
pub async fn task_command(
    input: &str,
    task_manager: &mut TaskManager,
    shell_executor: &Arc<ShellExecutorWithFixer>,
    config: &Arc<RwLock<Config>>,
) -> anyhow::Result<()> {
    // 解析子命令
    let subcommand = TaskSubcommand::parse(input)?;

    // 分发处理
    match subcommand {
        TaskSubcommand::Save { name } => {
            task_save_handler(name, task_manager).await?;
        }
        TaskSubcommand::List => {
            task_list_handler().await?;
        }
        TaskSubcommand::Load { id } => {
            task_load_handler(id, task_manager).await?;
        }
        TaskSubcommand::Show => {
            show_tasks_command(task_manager, config).await?;
        }
        TaskSubcommand::Delete { id } => {
            task_delete_handler(id).await?;
        }
        TaskSubcommand::Help => {
            print_task_help();
        }
    }

    Ok(())
}
```
