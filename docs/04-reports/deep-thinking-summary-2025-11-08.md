## 🎯 核心思想提炼

### 1. 技术与哲学的融合

**不是表面装饰，而是深层设计理念**:

```
技术层：
- LLM 推理
- Intent 匹配
- Tool 执行

哲学层：
- 易经占卜（象、数、理）
- 道德经（反者道之动）
- 系统思维（变化中的规律）

融合点：
- Intent 分析 = 起卦
- 推理过程 = 演算
- ExecutionPlan = 成卦
- 用户修改 = 变爻
- 执行结果 = 之卦
```

### 2. 仪式感的重要性

**为什么需要"复杂"的演算动画？**

- ❌ 不是为了炫技
- ✅ 是为了创造**神圣感**
- ✅ 是为了展示**推理深度**
- ✅ 是为了建立**情感连接**

**类比**:
```
现代科技：Apple 开机动画
古代仪式：蓍草演算、铜钱抛卦
RealConsole：意图占卜动画

共同点：将技术过程转化为体验仪式
```

### 3. 东方美学的现代表达

**设计语言**:
```
符号：☰☷☳☴☵☲☶☱（八卦）
颜色：金色（#FFD700）、土色（#8B4513）
字体：楷体、宋体（古典风格）
动画：流畅、优雅、含蓄
音效：钟声、磬声（古典乐器）
```

**不是简单的中文翻译，而是**:
- 用中国哲学思维方式
- 解决现代技术问题
- 创造独特的用户体验

### 4. Web 界面的独特价值

**充分发挥 Web 优势**:

| 维度 | CLI | Web（占卜系统） |
|------|-----|----------------|
| 视觉 | 单色文本 | SVG卦象 + Canvas演算 + 粒子效果 |
| 交互 | 键盘输入 | 拖拽步骤 + 悬停解释 + 抛卦手势 |
| 动画 | 字符闪烁 | 爻画生成 + 蓍草分堆 + 数字变化 |
| 音效 | 系统蜂鸣 | 钟声起卦 + 磬声成卦 + 爻变音效 |
| 状态 | 无状态 | 占卜历史 + 用户偏好持久化 |

## 🏗️ 技术架构总结

### 新增模块结构

```
src/agent/divination/
├── mod.rs                      # 模块导出
├── trigram.rs                  # 八卦系统（符号、颜色、映射）
├── hexagram.rs                 # 六十四卦系统（卦名、卦辞）
├── yarrow_stalks.rs            # 蓍草演算模拟（动画数据）
├── yao_mapping.rs              # 爻位映射（步骤→爻位）
├── judgement_generator.rs      # 卦辞生成（动态文本）
└── divination_engine.rs        # 占卜引擎（统一入口）
```

### 核心数据流

```
用户输入 "/decompose <查询>"
    ↓
Intent 识别 / LLM 拆解
    ↓
ExecutionPlan 生成
    ↓
DivinationEngine.divine(plan)  ← 新增
    ↓
生成 DivinationResult:
  - Hexagram（卦象）
  - YarrowSteps（演算步骤）
  - StepMappings（爻位映射）
  - Judgement（卦辞）
    ↓
通过 WebSocket 发送实时消息:
  1. DivinationStart（起卦）
  2. DivinationStep × N（演算，每100ms）
  3. DivinationHexagram（成卦）
  4. DivinationComplete（完成）
  5. IntentUnderstanding（增强版，附带占卜结果）
    ↓
前端 DivinationAnimation 类:
  1. 起卦动画（圆点旋转闪烁，200ms）
  2. 演算动画（数字变化+蓍草分堆，500ms）
  3. 成卦动画（爻画逐个生成，300ms）
  4. 显示卦象和卦辞
    ↓
用户看到完整的占卜过程和结果
```
