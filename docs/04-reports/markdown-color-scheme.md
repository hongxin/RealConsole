# Markdown 配色方案说明

## Claude Code 风格配色（v1.25.0+）

RealConsole 的 Markdown 渲染采用了 **Claude Code 风格**的优雅配色方案，提供专业、舒适的阅读体验。

## 配色详情

### 主题色：浅蓝色（RGB 100, 180, 255）

这是整体设计的主线，用于：
- 📑 **标题**（所有级别的标题）
- 🔘 **列表 bullet**（`•` 符号）
- 💻 **内联代码**（`` `code` ``）

**设计理念**：类似 Claude Code 的品牌色，传达专业、可信赖的感觉。

### 强调文字

| 元素 | 颜色 | RGB 值 | 视觉效果 |
|------|------|--------|----------|
| **粗体** | 明亮白色 | RGB(255, 255, 255) | 最强调层次，清晰但不刺眼 |
| *斜体* | 浅灰色 | RGB(180, 180, 180) | 次要强调，与粗体形成层次 |

**层次设计**：粗体 > 斜体 > 普通文字，三级视觉层次清晰。

### 代码块

```
代码块示例
使用护眼配色
```

| 属性 | 颜色 | RGB 值 | 设计目的 |
|------|------|--------|----------|
| 文字 | 柔和的绿色 | RGB(150, 220, 150) | 类似专业 IDE（VS Code、JetBrains） |
| 背景 | 深灰色 | RGB(40, 40, 40) | 低对比度，减少眼睛疲劳 |

**护眼设计**：柔和的绿色 + 深色背景 = 长时间阅读不疲劳。

### 辅助元素

| 元素 | 颜色 | RGB 值 | 用途 |
|------|------|--------|------|
| 段落文字 | 柔和白色 | RGB(240, 240, 240) | 稍微偏暖，长时间阅读更舒适 |
| 引用块标记 | 中等灰色 | RGB(120, 120, 120) | 适度区分，不抢眼 |

## 配色哲学

### 1. 主题一致性 🎨

使用**单一主题色**（浅蓝色）贯穿标题、内联代码、列表，保持视觉统一。

### 2. 层次分明 📊

```
强调层次：
  粗体（明亮白）
    ↓
  斜体（浅灰）
    ↓
  普通文字（柔和白）
```

通过颜色明暗差异，自然形成阅读焦点。

### 3. 护眼优先 💚

- 避免高饱和度颜色（黄色、品红色）
- 使用柔和、低对比度配色
- 代码块采用专业 IDE 风格（深色背景 + 柔和绿色）

### 4. 专业优雅 🧘

- 参考 Claude Code 的品牌配色
- 避免过于鲜艳、活泼的颜色
- 传达可靠、专业的印象

## 对比：旧配色 vs 新配色

| 元素 | 旧配色（v1.24.0） | 新配色（v1.25.0+） | 改进点 |
|------|------------------|-------------------|--------|
| 标题 | Cyan（纯青色） | 浅蓝色 RGB(100,180,255) | 更柔和、更优雅 |
| 粗体 | Yellow（纯黄色） | 明亮白色 RGB(255,255,255) | 不刺眼、更专业 |
| 斜体 | Magenta（品红色） | 浅灰色 RGB(180,180,180) | 层次更清晰 |
| 代码块 | Green + Black | 柔和绿 RGB(150,220,150) + 深灰 RGB(40,40,40) | 护眼、接近 IDE |
| 列表 | Yellow（黄色） | 浅蓝色 RGB(100,180,255) | 统一主题色 |

**总体提升**：
- ❌ 旧配色：鲜艳、对比强烈、类似终端默认色
- ✅ 新配色：柔和、专业、类似现代编辑器

## 使用建议

### 适合场景

✅ **长文档阅读**：配色柔和，减少眼睛疲劳
✅ **代码审查**：代码块配色接近 IDE，易于阅读
✅ **技术写作**：专业配色，提升内容可信度
✅ **夜间使用**：低对比度设计，夜间更舒适

### 配置选项

```yaml
# realconsole.yaml
display:
  markdown:
    enabled: true              # 启用 Markdown 渲染
    render_streaming: true     # 流式渲染（未来功能）
```

**开关自由**：随时通过配置启用/禁用，满足不同偏好。

## 技术实现

### RGB 精确控制

使用 termimad 的 `Color::Rgb` API，实现精确的颜色控制：

```rust
// 标题 - 柔和的浅蓝色
let header_color = Color::Rgb {
    r: 100,
    g: 180,
    b: 255,
};
skin.headers[0].set_fg(header_color);
```

**优势**：比系统预设颜色（Cyan、Yellow 等）更精细、更可控。

### 一致性保证

```rust
// 列表 bullet 使用与标题相同的颜色
skin.bullet = termimad::StyledChar::from_fg_char(
    Color::Rgb { r: 100, g: 180, b: 255 },  // 与 header_color 相同
    '•',
);
```

**设计原则**：重复使用主题色，保持视觉一致性。

## 未来优化

### 1. 可配置主题 🎨

```yaml
display:
  markdown:
    theme: claude-code  # 或 vscode-dark, github-light 等
```

支持多套预设主题，满足不同审美偏好。

### 2. 自定义颜色 🌈

```yaml
display:
  markdown:
    custom_colors:
      header: "rgb(100, 180, 255)"
      bold: "rgb(255, 255, 255)"
      # ...
```

让用户完全自定义配色方案。

### 3. 自适应配色 🌓

根据终端背景色（深色/浅色）自动调整配色方案。

RealConsole 的 Markdown 配色方案：

🎨 **主题一致**：单一主题色，视觉统一
📊 **层次分明**：三级强调层次，阅读焦点清晰
