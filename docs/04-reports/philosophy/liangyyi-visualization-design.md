# 两仪状态可视化命令设计

## 命令语法

```bash
/liangyyi [subcommand]
```

### 子命令

1. **`/liangyyi` 或 `/liangyyi status`** - 显示当前状态快照
2. **`/liangyyi history`** - 显示状态演化历史
3. **`/liangyyi stats`** - 显示详细统计信息
4. **`/liangyyi trend`** - 显示趋势分析

## 实现要点

### 1. 数据来源

- `StateTracker` - 状态追踪器
- `StateSnapshot` - 状态快照
- `StateStats` - 统计信息
- `detect_learning_phase()` - 学习阶段检测
- `analyze_trend()` - 趋势分析

### 2. 颜色方案

使用 `colored` crate：

```rust
use colored::Colorize;

// 阴阳能量
yin_energy.to_string().cyan()
yang_energy.to_string().red()

// 学习阶段
"探索期".red()
"稳定期".green()
"转变期".yellow()

// 趋势
"↗".green()
"↘".red()
"→".yellow()
```

### 3. Unicode 图表

使用 Unicode 字符绘制：

- 进度条: `▰▱`
- 趋势箭头: `↑↓→↗↘`
- 四象符号: `▅`
- 两仪符号: `☽☉`
- 状态指示: `🔴🟡🟢`

### 4. 数据格式化

```rust
// 能量值保留 2 位小数
format!("{:.2}", energy)

// 百分比
format!("{:.1}%", ratio * 100.0)

// 时间戳
format!("{}", timestamp.format("%H:%M:%S"))
```

## 集成点

### 1. Agent 命令路由

在 `src/agent.rs` 的 `handle_system_command()` 中添加：

```rust
if input.starts_with("/liangyyi") {
    return self.handle_liangyyi_command(input).await;
}
```

### 2. 新模块

创建 `src/commands/liangyyi.rs`：

```rust
pub struct LiangyiCommand {
    tracker: Arc<StateTracker>,
}

impl LiangyiCommand {
    pub async fn execute(&self, subcommand: Option<&str>) -> Result<String> {
        match subcommand {
            None | Some("status") => self.show_status().await,
            Some("history") => self.show_history().await,
            Some("stats") => self.show_stats().await,
            Some("trend") => self.show_trend().await,
            _ => Err(anyhow!("Unknown subcommand")),
        }
    }
}
```

### 3. 帮助文本

更新 `/help` 输出，添加：

```
/liangyyi [status|history|stats|trend]
    查看两仪演化系统状态
    - status:  当前状态快照
    - history: 演化历史
    - stats:   详细统计
    - trend:   趋势分析
```
