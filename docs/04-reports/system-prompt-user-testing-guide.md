# 系统提示词功能 - 用户测试指南

**版本**: v1.23.1
**测试周期**: 建议 1-2 周
**创建日期**: 2025-01-05

---

## 📋 测试目标

通过实际使用场景，验证系统提示词功能的实用性和设计合理性，为后续优化提供依据。

### 核心问题
1. **是否有用？** - 提示词是否真的影响 LLM 行为？
2. **是否易用？** - 命令接口是否直观？
3. **是否够用？** - 当前功能是否满足需求？
4. **需要什么？** - 最希望添加什么功能？

---

## 🚀 快速开始

### 前置准备

```bash
# 1. 确保使用最新编译版本
cd /Users/hongxin/Workspace/claude-ai-playground/RealConsole
cargo build --release

# 2. 检查配置
cat realconsole.yaml | grep -A 5 "system_prompt"

# 3. 启动 RealConsole
DEEPSEEK_API_KEY="你的API密钥" ./target/release/realconsole
```

### 基础命令一览

```bash
/show-prompt                    # 查看当前系统提示词
/set-prompt <prompt>            # 设置自定义提示词
/set-prompt reset               # 重置为配置文件默认值
/help                           # 查看所有命令
```

#### 任务 1.3：验证提示词生效

```bash
# 1. 设置为代码审查专家
/set-prompt 你是专业的代码审查助手，专注于发现安全漏洞和性能问题

# 2. 让 LLM 审查一段代码
请审查这段代码：
fn get_user(id: &str) -> String {
    format!("SELECT * FROM users WHERE id = {}", id)
}

# 3. 观察 LLM 的回答风格
```

**评估标准**:
- [ ] LLM 是否以"代码审查"的视角回答？
- [ ] 是否主动提到安全问题（SQL 注入）？
- [ ] 回答是否专业和详细？

**对比测试**:
```bash
# 重置为默认提示词
/set-prompt reset

# 再次提问相同问题
请审查这段代码：
fn get_user(id: &str) -> String {
    format!("SELECT * FROM users WHERE id = {}", id)
}
```

**记录对比**:
```
自定义提示词的回答：
[记录 LLM 回答要点]

默认提示词的回答：
[记录 LLM 回答要点]

差异分析：
- 是否有明显区别？
- 哪个更符合需求？
- 提示词的价值如何？
```

**步骤**:
