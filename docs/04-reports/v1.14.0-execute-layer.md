### 1. StateTracker 结构扩展

### 2. 关键方法

**enable_adaptive()** - 启用自适应
```rust
pub fn enable_adaptive(&mut self, target: TargetState)
```

**apply_recommendations()** - 应用建议到配置
```rust
pub async fn apply_recommendations(&self, recommendations: &[Recommendation]) -> Result<()>
```

**映射规则**：
- `efficiency` → `energy_decay_rate`
- `activity` → `low/high_activity_threshold`
- `load` → `snapshot_interval`
- `context` → `history_size`

**auto_optimize()** - 自动优化（核心）
```rust
pub async fn auto_optimize(&self) -> Result<Vec<Recommendation>> {
    // 1. 获取当前状态向量
    // 2. 添加到自适应系统
    // 3. 生成建议
    // 4. 应用建议到配置
    // 5. 返回建议列表
}
```

**get_recommendations()** - 获取建议（不应用）
```rust
pub async fn get_recommendations(&self) -> Result<Vec<Recommendation>>
```

## 维度到配置映射

| StateVector 维度 | StateTrackerConfig 参数 | 映射逻辑 |
|------------------|------------------------|---------|
| efficiency | energy_decay_rate | 低效率→增加衰减（快速重置）；高效率→减少衰减（保持稳定） |
| activity | low/high_activity_threshold | 低活动→降低阈值（易触发）；高活动→提高阈值（保持） |
| load | snapshot_interval | 低负载→增加间隔（节省资源）；高负载→减少间隔（频繁观测） |
| context | history_size | 高上下文→增加历史（保留更多）；低上下文→减少历史（节省内存） |

## 使用示例

```rust
use realconsole::liangyyi::{StateTracker, StateTrackerConfig};
use realconsole::liangyyi::adaptive::TargetState;

// 创建追踪器并启用自适应
let mut tracker = StateTracker::new(StateTrackerConfig::default());
tracker.enable_adaptive(TargetState::balanced());

// 定期调用自动优化
loop {
    // 系统正常运行...

    // 每隔一段时间优化一次
    let recommendations = tracker.auto_optimize().await?;

    for rec in recommendations.iter().take(3) {
        println!("🎯 {}: {} (优先级: {:.2})",
            rec.dimension, rec.reason, rec.priority);
    }

    tokio::time::sleep(Duration::from_secs(60)).await;
}
```

输出示例：
```
🎯 efficiency: 当前值 0.45 低于目标范围 [0.60, 0.80] (优先级: 0.15)
🎯 activity: 当前值 0.85 高于目标范围 [0.50, 0.70] (优先级: 0.15)
🎯 load: 当前值 0.62 高于目标范围 [0.30, 0.50] (优先级: 0.12)
```
