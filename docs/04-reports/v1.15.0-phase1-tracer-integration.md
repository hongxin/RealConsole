## 四维到 StateVector 映射规则

| Tracer 维度 | StateVector 维度 | 映射逻辑 | 融合比例 |
|-------------|-----------------|---------|---------|
| **Statistics** 📊 | efficiency | 成功率 = Success条目 / 总条目 | 基础60% + Tracer40% |
| **Coordination** 🔗 | activity | 活跃度 = 条目数 / 时间跨度 | 基础50% + Tracer50% |
| **BlackBox** 🤖 | load | 负载 = LLM调用密度 / 20 | 基础60% + Tracer40% |
| **Memory** 💭 | context | 上下文强度 = 切换数 / 总条目 | 基础50% + Tracer50% |

### 映射实现示例

**Statistics → efficiency**:
```rust
let success_count = stats_entries
    .iter()
    .filter(|e| e.status.is_success())
    .count() as f64;
let success_rate = success_count / total;

// 融合
let enhanced_efficiency = base_efficiency * 0.6 + success_rate * 0.4;
```

**Coordination → activity**:
```rust
let duration_secs = (last.timestamp - first.timestamp).num_seconds() as f64;
let activity_rate = (coord_entries.len() as f64 / duration_secs).min(1.0);

// 融合
let enhanced_activity = base_activity * 0.5 + activity_rate * 0.5;
```

## 使用示例

### 基础使用

```rust
use realconsole::liangyyi::{StateTracker, StateTrackerConfig};
use realconsole::tracer::UnifiedTracer;
use std::sync::Arc;

// 创建追踪器
let mut tracker = StateTracker::new(StateTrackerConfig::default());

// 创建并设置 Tracer（需要 History, ExecutionLogger 等依赖）
let tracer = UnifiedTracer::new(history, exec_logger, llm_logger, context);
tracker.set_tracer(Arc::new(tracer));

// 检查是否启用
assert!(tracker.is_tracer_enabled());

// 使用增强的状态向量
let enhanced_vector = tracker.to_state_vector_enhanced().await;
println!("增强效率: {:.2}", enhanced_vector.get("efficiency").unwrap());
```

### 与自适应系统协同

```rust
// 启用自适应
tracker.enable_adaptive(TargetState::balanced());

// 系统运行中...
loop {
    // 事件驱动状态更新
    tracker.update_from_event(event).await;

    // 定期优化（内部使用 enhanced vector）
    if should_optimize() {
        let recommendations = tracker.auto_optimize().await?;

        for rec in recommendations.iter().take(3) {
            println!("🎯 {}: {}", rec.dimension, rec.reason);
        }
    }

    tokio::time::sleep(Duration::from_secs(60)).await;
}
```

## 技术亮点

### 1. 非侵入式集成
- 通过 `Option<Arc<UnifiedTracer>>` 可选启用
- 未启用时，`to_state_vector_enhanced()` 等同于 `to_state_vector()`
- 零性能开销

### 2. 多源数据融合
- 基础状态（来自 Taiji/Sixiang）
- Tracer 观测数据（四维追踪）
- 加权融合，保留双方优势

### 3. 线程安全
- `Arc<UnifiedTracer>` 支持跨线程共享
- 所有异步查询都是非阻塞的

### 4. 灵活映射
- 清晰的四维到状态向量映射规则
- 可调整的融合比例
- 易于扩展新维度

## 性能影响

### 查询开销

- 每次 `to_state_vector_enhanced()` 调用：
  - 4 个并行查询（Statistics/Coordination/BlackBox/Memory）
  - 每个查询限制 20 条
  - 时间复杂度：O(n log n)（排序开销）
  - 实际耗时：< 1ms（内存操作）

### 内存开销

- `tracer` 字段：`Option<Arc<_>>` = 8 bytes（未启用时）
- 查询结果：4 × 20 × sizeof(TraceEntry) ≈ 10KB（临时）

### 优化措施

1. **惰性查询**：仅在调用 `to_state_vector_enhanced()` 时查询
2. **限制数量**：每维度最多 20 条，避免大量数据传输
3. **并行查询**：4 个维度并行，减少总延迟
4. **Arc共享**：避免 Tracer 数据复制
