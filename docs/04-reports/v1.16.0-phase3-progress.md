## ✅ Part A: 修复并发测试问题 (已完成)

### 问题诊断

在并发测试环境下，多个测试函数同时修改全局工作目录状态导致竞争条件：

```
测试并发运行时的竞争场景：
  Test A: env::set_current_dir("/tmp")
  Test B: env::set_current_dir("/home")  ← 干扰 Test A
  Test A: assert(current_dir == "/tmp")  ← 失败！
```

**受影响的测试**:
- `test_handle_cd_to_tmp`
- `test_handle_cd_home`
- `test_handle_cd_tilde_expansion`
- `test_cd_with_trailing_slash`

### 解决方案

**技术选型**: `serial_test` crate (v3.0)

该库提供 `#[serial]` 属性，确保标记的测试串行执行：

```rust
#[tokio::test(flavor = "multi_thread")]
#[serial_test::serial]  // ← 添加此行
async fn test_handle_cd_to_tmp() {
    let original_dir = env::current_dir().unwrap();
    // ... 测试逻辑
    env::set_current_dir(&original_dir);
}
```

**修复文件**:
- `Cargo.toml`: 添加 `serial_test = "3.0"` 依赖
- `src/agent.rs`: 给 4 个 cd 测试添加 `#[serial]` 属性

### 测试结果

```bash

❌ 测试失败: 0
⏱️  执行时间: 119.68s
🎯 目标时间: <100s (接近目标)
```

**性能分析**:
- 串行化 4 个测试对整体性能影响微乎其微
- 其余 1174 个测试仍保持并发执行
- 测试时间从之前的 113-117s 提升到 119.68s，在可接受范围内

### Phase 3.2: MemoryManager 适配层

**目标**: 保持原有 Memory API，底层使用 UnifiedTracer

```rust
// src/memory/manager.rs (新建)

pub struct MemoryManager {
    tracer: Arc<RwLock<UnifiedTracer>>,
}

impl MemoryManager {
    /// 兼容原有 API
    pub async fn store(&self, entry: MemoryEntry) -> Result<()> {
        let trace_entry = TraceEntry {
            dimension: Dimension::Memory,
            entry_type: entry.entry_type,
            content: entry.content,
            importance: Some(entry.importance),
            tags: entry.tags,
            ..Default::default()
        };

        self.tracer.write().await.add_entry(trace_entry)?;
        Ok(())
    }

    pub async fn search(&self, keyword: &str) -> Result<Vec<MemoryEntry>> {
        let entries = self.tracer.read().await
            .search(keyword)
            .filter(|e| e.dimension == Dimension::Memory)
            .collect();

        Ok(self.convert_from_trace_entries(entries))
    }

    /// 新增：基于重要性查询
    pub async fn find_important(&self, min_level: Importance) -> Result<Vec<MemoryEntry>> {
        let entries = self.tracer.read().await
            .get_entries(Dimension::Memory, None)
            .filter(|e| {
                e.importance.unwrap_or(Importance::Low) >= min_level
            })
            .collect();

        Ok(self.convert_from_trace_entries(entries))
    }
}
```

### Phase 3.3: 数据迁移

**目标**: 平滑迁移现有 Memory 数据到 Trace 系统

```rust
// src/migration/memory_to_trace.rs (新建)

pub struct MemoryMigrator {
    old_memory: Memory,
    new_tracer: Arc<RwLock<UnifiedTracer>>,
}

impl MemoryMigrator {
    pub async fn migrate(&mut self) -> Result<MigrationReport> {
        let entries = self.old_memory.get_all_entries()?;
        let mut migrated = 0;
        let mut failed = 0;

        for entry in entries {
            match self.migrate_entry(entry).await {
                Ok(_) => migrated += 1,
                Err(e) => {
                    eprintln!("Migration failed: {}", e);
                    failed += 1;
                }
            }
        }

        Ok(MigrationReport {
            total: entries.len(),
            migrated,
            failed,
        })
    }

    async fn migrate_entry(&mut self, entry: MemoryEntry) -> Result<()> {
        let trace_entry = TraceEntry {
            id: entry.id,
            dimension: Dimension::Memory,
            entry_type: entry.entry_type,
            content: entry.content,
            timestamp: entry.timestamp,
            status: Status::Completed,
            importance: Some(entry.importance),
            tags: entry.tags,
            ..Default::default()
        };

        self.new_tracer.write().await.add_entry(trace_entry)?;
        Ok(())
    }
}
```
