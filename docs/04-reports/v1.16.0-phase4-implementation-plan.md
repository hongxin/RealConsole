#### Task A.1: 修复 ContextMessage 类型映射语义丢失
**优先级**: 🔴 高
**预计时间**: 2 小时
**问题描述**:
- `EntryType::ContextMessage` 可能来自 `MemoryEntryType::User` 或 `MemoryEntryType::Assistant`
- 当前实现统一映射为 `User`，导致 `dump()` 后 Assistant 消息被错误标记

**解决方案**:
```rust
// 在 memory_entry_to_trace 中保存原始类型
fn memory_entry_to_trace(&self, entry: &MemoryEntry) -> TraceEntry {
    let mut trace_entry = TraceEntry::new(/* ... */);

    // 在 metadata 中保存原始类型
    trace_entry.add_metadata(
        "original_memory_type".to_string(),
        serde_json::json!(entry.entry_type.to_string()),
    );

    trace_entry
}

// 在 trace_to_memory_entry 中优先恢复原始类型
fn trace_to_memory_entry(&self, entry: &TraceEntry) -> MemoryEntry {
    let memory_type = entry
        .get_metadata("original_memory_type")
        .and_then(|v| v.as_str())
        .and_then(|s| MemoryEntryType::from_str(s).ok())
        .unwrap_or_else(|| self.trace_type_to_memory_type(&entry.entry_type));
    // ...
}
```

**修改文件**:
- `src/memory/manager.rs` (类型转换方法)
- `src/memory/memory_core.rs` (可能需要实现 `FromStr` trait)

**测试计划**:
```rust

    let manager = create_test_manager();

async fn test_large_file_migration() {
    let manager = create_test_manager();
    let migrator = MemoryMigrator::new(manager);

    // 创建包含 10,000 条目的测试文件
    let mut temp_file = NamedTempFile::new().unwrap();

    }

    let duration = start.elapsed();

    assert_eq!(report.total, 10_000);
    assert_eq!(report.migrated, 10_000);
    assert!(duration.as_secs() < 10, "迁移耗时过长: {:?}", duration);
}

#[tokio::test]
async fn test_migration_error_recovery() {
    let manager = create_test_manager();
    let migrator = MemoryMigrator::new(manager);

    let mut temp_file = NamedTempFile::new().unwrap();

    // 混合有效和无效数据
    for i in 0..100 {
        if i % 10 == 0 {
            writeln!(temp_file, "{{invalid json}}").unwrap();
        } else {
            let entry = MemoryEntry::new(format!("Entry {}", i), EntryType::User);
            writeln!(temp_file, "{}", serde_json::to_string(&entry).unwrap()).unwrap();
        }
    }
    temp_file.flush().unwrap();

    let report = migrator.migrate_from_file(temp_file.path()).await.unwrap();

    assert_eq!(report.total, 100);
    assert_eq!(report.migrated, 90);
    assert_eq!(report.failed, 10);
    assert_eq!(report.success_rate(), 90.0);
}
```
