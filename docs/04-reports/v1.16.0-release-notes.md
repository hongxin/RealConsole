# RealConsole v1.16.0 发布说明

**发布日期**: 2025-10-31
**版本类型**: 重大功能更新
**主题**: Memory 模块统一重构

---

## 🌟 核心亮点

### 1. Memory 统一到 UnifiedTracer ✨

v1.16.0 将 Memory 模块完全重构，统一到 UnifiedTracer 四维观测体系：

```
旧架构: Memory ──> 独立 JSONL 存储

新架构: MemoryManager ──> UnifiedTracer
                          ├─ Statistics 维度
                          ├─ Coordination 维度
                          ├─ BlackBox 维度
                          └─ Memory 维度 ⭐
```

**四大收益**:
- 🏗️ **统一架构**: 四维观测一体化
- ⚡ **性能提升**: 多线程场景 2-4x 提升
- ✨ **功能增强**: tags、importance、context_id
- 🔍 **更强查询**: 标签搜索、重要性过滤、上下文关联

## 🎁 新功能

### 异步 Memory API

所有 Memory 方法升级为异步：

```rust
// v1.15.x (旧)
manager.add("学习 Rust".to_string(), EntryType::User);
let recent = manager.recent(10)?;

// v1.16.0 (新)
manager.add("学习 Rust".to_string(), EntryType::User).await;
let recent = manager.recent(10).await?;
```

### 重要性标记系统

为记忆添加四级重要性标记：

```rust
manager.add_with_importance(
    "重要项目决策".to_string(),
    EntryType::Assistant,
    Importance::Critical,  // Low/Normal/Important/Critical
).await;

// 查询所有重要记忆
let important = manager.find_important().await?;
```

### 标签系统

支持自定义标签和标签查询：

```rust
// 添加标签（通过 TraceEntry）
let mut entry = TraceEntry::new(/* ... */);
entry.add_tag("learning".to_string());
entry.add_tag("rust".to_string());

// 标签搜索
let results = manager.search_by_tag("learning").await?;
```

### 上下文关联

通过 context_id 关联相关记忆：

```rust
// 设置上下文
entry.set_context_id("project-x".to_string());

// 查询相关记忆
let related = manager.find_by_context("project-x").await?;
```

## 🔧 Bug 修复

### 修复 Assistant 类型丢失问题

**问题**: v1.15.x 中，Assistant 消息在 `dump()` 后会被错误标记为 User 类型

**修复**: 在 metadata 中保存原始类型，优先恢复机制

```rust
// 现在所有类型往返转换 100% 保留
manager.add("AI 回复".to_string(), EntryType::Assistant).await;
let entries = manager.dump().await?;
assert_eq!(entries[0].entry_type, EntryType::Assistant); // ✅ 正确保留
```

## 🎯 Breaking Changes

### API 变更

⚠️ **所有 Memory 方法改为异步**

需要在所有 Memory 方法调用后添加 `.await`：

```rust
// 影响的方法
manager.add(/*...*/).await;
manager.recent(10).await?;
manager.search("keyword").await?;
manager.dump().await?;
manager.stats().await?;
// ... 所有 Memory 方法
```

### 数据存储变更

- ❌ **旧存储**: 独立 JSONL 文件（`~/.realconsole/memory/memory.jsonl`）
- ✅ **新存储**: UnifiedTracer 统一存储

**需要迁移**: 使用迁移工具一键迁移（见上文）

## 🚀 升级步骤

### 1. 下载新版本

```bash
# 从源码安装
git clone https://github.com/hongxin/RealConsole.git
cd RealConsole
git checkout v1.16.0
```

### 2. 备份数据

```bash
# 备份 Memory 数据
cp ~/.realconsole/memory/memory.jsonl \
   ~/.realconsole/memory/memory.jsonl.backup.$(date +%Y%m%d)

# 或备份整个目录
tar -czf ~/.realconsole/memory_backup_$(date +%Y%m%d).tar.gz \
   ~/.realconsole/memory/
```

### 3. 编译安装

```bash
make install
# 或
cargo build --release
cp target/release/realconsole ~/.local/bin/
```

### 4. 运行迁移

```bash
cargo run --bin migrate_memory
```

### 5. 验证升级

```bash
realconsole --version
# RealConsole v1.16.0

realconsole
> /memory stats
```

### 常见问题

Q: **迁移会丢失数据吗？**
A: 不会。迁移工具采用容错设计，建议迁移前备份数据。

Q: **性能会变差吗？**
A: 多线程场景更快（2-4x），单线程稍慢但仍在微秒级。

Q: **可以回滚吗？**
A: 可以。参考迁移指南的回滚方案。

Q: **Assistant 类型还会丢失吗？**
A: 不会。Phase 4 已修复此 bug，类型 100% 保留。
