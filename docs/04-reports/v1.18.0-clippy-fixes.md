### 优先级 1: 简单修复（15 分钟）

#### 1. literal_empty_format (5个) ✅
**位置**: src/config/wizard.rs
**问题**: 字面量使用空格式字符串
```rust
// 错误
println!("\n{} {}", "📝 步骤 1/5:".bold(), "LLM 后端选择");

// 正确
println!("\n{} {}", "📝 步骤 1/5:".bold(), format!("LLM 后端选择"));
// 或者更简单
println!("\n{} LLM 后端选择", "📝 步骤 1/5:".bold());
```

**行号**: 228, 349, 382, 415, 440

#### 3. loop_counter (1个) ✅
**位置**: src/commands/llm_log.rs:765

### 优先级 3: 复杂修复（30 分钟）

#### 10. too_many_arguments (1个) ✅
**位置**: src/llm/logger.rs:239
**问题**: 函数参数过多（9个 > 7个）

**方案**: 封装为结构体
```rust
// 错误
pub async fn log_interaction(
    &self,
    session_id: String,
    model: String,
    prompt: String,
    response: String,
    tokens_used: Option<usize>,
    latency_ms: Option<u64>,
    error: Option<String>,
    context: Option<CallContext>,
)

// 正确
pub struct LogRequest {
    pub session_id: String,
    pub model: String,
    pub prompt: String,
    pub response: String,
    pub tokens_used: Option<usize>,
    pub latency_ms: Option<u64>,
    pub error: Option<String>,
    pub context: Option<CallContext>,
}

pub async fn log_interaction(&self, request: LogRequest)
```
