**日期**: 2025-11-07

---

## 一、功能概述

### 1.1 核心功能

将 Web 终端的对话历史以「回合卡片」形式展示，每个回合包含：

- **回合编号**: Round #1, #2, #3...
- **状态指示**:
  - ⏸ Pending（灰色）
  - ⏳ Running（青色，闪烁动画）
  - ✓ Success（绿色，发光）
  - ✗ Error（粉色，发光）
- **执行时间**: 精确到小数点后2位（如 `1.23s`）
- **工具使用**: 工具名称徽章（如 `FileRead`, `ShellExec`）
- **用户输入**: 完整的用户命令或问题
- **AI 响应**: 带 Markdown 渲染的完整回答
- **折叠/展开**: 点击回合头部可折叠历史回合

### 1.2 设计目标

1. **可视化结构**: 将对话从流式文本转变为结构化卡片
2. **元数据追踪**: 显示执行时间、工具使用等诊断信息
3. **交互优化**: 支持折叠历史回合，减少视觉干扰
4. **为 v1.31.0 铺路**: 为未来的 Cell 执行模型打基础

## 二、实施变更

### 2.1 后端变更

#### `src/web/session.rs` (+115 行)

**新增数据结构**:
```rust
// 回合状态枚举（4 种状态）
pub enum RoundStatus {
    Pending,
    Running,
    Success,
    Error { message: String },
}

// 对话回合结构（9 个字段）
pub struct ConversationRound {
    pub id: String,              // UUID 格式
    pub index: usize,            // 1, 2, 3...
    pub user_input: String,
    pub ai_response: String,
    pub tools_used: Vec<String>,
    pub execution_time: f64,     // 秒
    pub status: RoundStatus,
    pub timestamp: DateTime<Utc>,
    pub model: String,
}
```

**新增消息类型**:
```rust
pub enum ServerMessage {
    // ... 原有消息 ...
    RoundStart { round: ConversationRound },
    RoundUpdate { round_id: String, status: RoundStatus },
    RoundComplete { round: ConversationRound },
    RoundHistory { rounds: Vec<ConversationRound> },
}
```

**Session 扩展**:
- 新增字段: `rounds: Arc<RwLock<Vec<ConversationRound>>>`
- 新增方法:
  - `create_round()` - 创建新回合
  - `complete_round()` - 完成回合
  - `fail_round()` - 标记失败
  - `update_round_status()` - 更新状态
  - `get_rounds()` - 获取历史
  - `current_round()` - 获取当前

#### `src/web/websocket.rs` (+60 行)

**LLM 执行流程重构**:
```rust
async fn execute_llm_chat() {
    // 1. 创建回合
    let round = session.create_round(input, model).await;
    send(RoundStart { round });

    // 2. 记录时间
    let start = Instant::now();

    // 3. 执行 LLM
    let response = agent.llm_service().process(request).await;

    // 4. 提取工具使用
    let tools = extract_tools_from_response(&response);

    // 5. 完成回合
    let time = start.elapsed().as_secs_f64();
    session.complete_round(round_id, response, time, tools).await;
    send(RoundComplete { round });
}
```

**工具提取逻辑**:
- 解析 LLM 响应中的 `__DEBUG__` 部分
- 提取 `Tool: xxx` 标记
- 返回工具名称列表（去重）

### 2.2 前端变更

#### `src/web/server.rs` (+280 行 CSS + JavaScript)

**WebSocket 消息处理**:
```javascript
case 'round_start':
    terminal.createRound(msg.round);
    break;
case 'round_complete':
    terminal.completeRound(msg.round);
    break;
case 'round_history':
    msg.rounds.forEach(r => {
        terminal.createRound(r);
        terminal.completeRound(r);
    });
    break;
```

**核心 JavaScript 方法**:
- `createRound(round)` - 创建回合 DOM 元素
- `createRoundElement(round)` - 构建卡片 HTML 结构
- `completeRound(roundData)` - 更新回合完成数据
- `updateRoundStatus(roundId, status)` - 更新状态图标
- `toggleRound(roundId)` - 折叠/展开切换
- `getStatusIcon(status)` - 状态图标映射
- `renderTools(tools)` - 渲染工具徽章

**CSS 样式（280 行）**:
- **赛博朋克主题**: 霓虹色、发光效果、半透明背景
- **卡片样式**: 边框发光、悬停效果、毛玻璃效果
- **状态颜色**:
  - Pending: `#888` (灰色)
  - Running: `#00f0ff` (青色) + 脉冲动画
  - Success: `#39ff14` (霓虹绿) + 发光
  - Error: `#ff006e` (霓虹粉) + 发光
- **动画效果**:
  - `status-pulse` - 状态脉冲
  - `max-height` 过渡 - 折叠展开
  - `opacity` 淡入淡出
- **响应式**: 移动端适配（768px 断点）

## 六、已知问题与限制

### 6.1 当前限制

1. **历史持久化**:
   - 回合历史仅保存在内存中
   - 服务器重启后历史丢失
   - **计划**: v1.30.0 实现持久化存储

2. **工具提取准确性**:
   - 依赖 `__DEBUG__` 部分的格式
   - 如果 LLM 响应格式变化可能失效
   - **改进**: 更鲁棒的解析逻辑

3. **回合编辑功能**:
   - 当前不支持修改历史回合
   - **计划**: v1.31.0 的 Cell 模型支持编辑

4. **导出功能**:
   - 暂不支持导出回合历史（JSON/Markdown）
   - **计划**: v1.32.0 实现导出

### 6.2 已知 Bug

- 无（截至实施完成）
