#### 核心功能实现

**1. Trigram（八卦）**
- 8个卦象枚举：乾☰ 坤☷ 震☳ 巽☴ 坎☵ 离☲ 艮☶ 兑☱
- 工具名称智能映射（`from_tool_name`）
- 卦象符号、名称、属性、颜色

**2. Hexagram（六十四卦）**
- 上下卦组合生成卦名
- 15个常见卦辞（乾为天、坤为地、水火既济等）
- 完整卦象描述生成

**3. YarrowStalks（蓍草演算）**
- 简化演算：大衍 → 分二 → 挂一 → 揲四 → 归奇 → 成卦
- 传统演算：支持三变成爻（备用）
- 为动画生成步骤数据

**4. YaoMapping（爻位映射）**
- 6个爻位：初爻、二爻、三爻、四爻、五爻、上爻
- 每个爻位的爻辞和建议
- 步骤到爻位的自动映射

**5. JudgementGenerator（卦辞生成）**
- 根据步骤数评估任务复杂度
- 动态生成执行建议
- 特定卦象的专业建议
- 支持完整占卜报告（含爻位分析）

**6. DivinationEngine（占卜引擎）**
- 统一入口：`divine(plan)` → `DivinationResult`
- 自动选择上下卦（首尾步骤工具）
- 生成完整占卜数据（卦象 + 演算 + 爻位 + 卦辞）
- 支持快速占卜（`divine_quick`）和完整报告（`divine_with_full_report`）

## 🎓 技术亮点

### 1. 模块化设计
每个模块职责单一，易于测试和扩展：
- trigram: 只负责八卦
- hexagram: 只负责六十四卦
- yarrow_stalks: 只负责演算模拟
- 等等...

### 2. 类型安全
所有占卜数据都是强类型，支持 `Serialize` + `Deserialize`：
```rust
pub struct DivinationResult {
    pub hexagram: Hexagram,
    pub yarrow_steps: Vec<YarrowStep>,
    pub step_mappings: Vec<StepYaoMapping>,
    pub full_judgement: String,
}
```

### 3. 灵活扩展
- 支持快速占卜（无动画）：`divine_quick()`
- 支持完整报告（含爻位）：`divine_with_full_report()`
- 支持传统演算（三变成爻）：`simulate_traditional()`

### 4. 性能优化
- 字符串常量（避免重复分配）
- 轻量级枚举（Copy trait）
- 最小化内存拷贝
