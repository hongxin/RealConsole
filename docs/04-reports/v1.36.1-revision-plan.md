## 🎯 修订背景

### v1.36.0 的问题诊断

**根本问题**：把易经当成了"装饰层"，而非"核心哲学"

**具体表现**：
1. ❌ 卦象是意图拆解完成后的"展示"，而非"分析"
2. ❌ 步骤与爻位的对应是简单的"序号映射"，而非"语义融合"
3. ❌ 复杂的起卦动画是"形式主义"，而非"实质内容"
4. ❌ 态势评估是"神秘化包装"，而非"科学分析"
5. ❌ 变化响应缺失，无法体现"易变"的核心

**需要保留的**：
- ✅ 后端占卜引擎的基础结构（7个模块）
- ✅ 八卦到工具类型的映射逻辑
- ✅ 配置系统的基础框架
- ✅ WebSocket 消息协议

**需要移除的**：
- ❌ 复杂的前端起卦动画
- ❌ 蓍草演算可视化
- ❌ 神秘化的卦辞表达
- ❌ 过度的视觉效果

**需要重构的**：
- 🔄 YaoPosition 的语义定义
- 🔄 步骤与爻位的映射逻辑
- 🔄 态势分析的评估体系

#### 1.2 步骤性质分析系统

**目标**：自动分析每个步骤的本质性质

**新增模块**：`src/agent/divination/step_analyzer.rs`

```rust
use crate::agent::decomposition::Step;

/// 步骤的本质性质
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum StepNature {
    /// 准备型：配置、读取、初始化
    Preparation,
    /// 执行型：操作、写入、触发
    Execution,
    /// 决策型：判断、选择、分支
    Decision,
    /// 处理型：转换、计算、过滤
    Processing,
    /// 收尾型：汇总、输出、确认
    Finalization,
    /// 清理型：关闭、释放、保存
    Cleanup,
}

pub struct StepAnalyzer;

impl StepAnalyzer {
    /// 分析步骤的本质性质
    pub fn analyze_nature(step: &Step) -> StepNature {
        // 1. 基于工具类型的初步判断
        let tool_based = Self::infer_from_tool(&step.tool);

        // 2. 基于步骤描述的语义分析
        let desc_based = Self::infer_from_description(&step.description);

        // 3. 基于参数的细化分析
        let param_based = Self::infer_from_params(&step.params);

        // 4. 综合判断
        Self::combine_inferences(tool_based, desc_based, param_based)
    }

    fn infer_from_tool(tool: &str) -> StepNature {
        match tool {
            // 准备型工具
            "read_file" | "list_directory" | "check_status" | "get_config" =>
                StepNature::Preparation,

            // 执行型工具
            "write_file" | "execute_command" | "create_directory" | "delete_file" =>
                StepNature::Execution,

            // 决策型工具（通常需要后续分支）
            "search" | "grep" | "find" | "filter" =>
                StepNature::Decision,

            // 处理型工具
            "transform" | "calculate" | "sort" | "merge" =>
                StepNature::Processing,

            // 收尾型工具
            "output" | "display" | "format" | "summarize" =>
                StepNature::Finalization,

            // 清理型工具
            "cleanup" | "close" | "save_state" | "disconnect" =>
                StepNature::Cleanup,

            _ => StepNature::Processing  // 默认
        }
    }

    fn infer_from_description(desc: &str) -> StepNature {
        let desc_lower = desc.to_lowercase();

        // 准备型关键词
        if desc_lower.contains("读取") || desc_lower.contains("加载")
            || desc_lower.contains("初始化") || desc_lower.contains("配置") {
            return StepNature::Preparation;
        }

        // 决策型关键词
        if desc_lower.contains("检查") || desc_lower.contains("判断")
            || desc_lower.contains("如果") || desc_lower.contains("选择") {
            return StepNature::Decision;
        }

        // 清理型关键词
        if desc_lower.contains("清理") || desc_lower.contains("关闭")
            || desc_lower.contains("释放") || desc_lower.contains("保存") {
            return StepNature::Cleanup;
        }

        // 收尾型关键词
        if desc_lower.contains("输出") || desc_lower.contains("显示")
            || desc_lower.contains("返回") || desc_lower.contains("完成") {
            return StepNature::Finalization;
        }

        StepNature::Processing  // 默认
    }

    fn infer_from_params(params: &serde_json::Value) -> StepNature {
        // 基于参数的细化判断
        // 例如：如果有 "output" 参数，可能是 Finalization
        // 如果有 "cleanup" 参数，可能是 Cleanup
        StepNature::Processing  // 简化实现
    }

    fn combine_inferences(
        tool: StepNature,
        desc: StepNature,
        param: StepNature,
    ) -> StepNature {
        // 优先级：描述 > 工具 > 参数
        if desc != StepNature::Processing {
            desc
        } else if tool != StepNature::Processing {
            tool
        } else {
            param
        }
    }
}
```

#### 1.3 步骤顺序验证系统

**目标**：检查步骤顺序是否符合爻位逻辑

**新增功能**：`ExecutionPlan::validate_sequence()`

```rust
use crate::agent::divination::{YaoPosition, StepAnalyzer, StepNature};

pub struct SequenceValidation {
    pub is_valid: bool,
    pub issues: Vec<SequenceIssue>,
    pub suggestions: Vec<SequenceSuggestion>,
}

pub struct SequenceIssue {
    pub step_index: usize,
    pub severity: IssueSeverity,
    pub description: String,
}

pub enum IssueSeverity {
    Critical,   // 必须修正
    Warning,    // 建议修正
    Info,       // 仅供参考
}

pub struct SequenceSuggestion {
    pub action: SuggestionAction,
    pub description: String,
    pub expected_benefit: String,
}

pub enum SuggestionAction {
    Reorder { from: usize, to: usize },
    Split { at: usize },
    Merge { indices: Vec<usize> },
    AddStep { at: usize, nature: StepNature },
}

impl ExecutionPlan {
    /// 验证步骤顺序是否符合爻位逻辑
    pub fn validate_sequence(&self) -> SequenceValidation {
        let mut issues = Vec::new();
        let mut suggestions = Vec::new();

        // 1. 检查每个步骤是否在合适的位置
        for (i, step) in self.steps.iter().enumerate() {
            let actual_nature = StepAnalyzer::analyze_nature(step);
            let yao_pos = YaoPosition::from_index(i);
            let expected_nature = yao_pos.expected_nature();

            if actual_nature != expected_nature {
                issues.push(SequenceIssue {
                    step_index: i,
                    severity: Self::calculate_severity(actual_nature, expected_nature),
                    description: format!(
                        "步骤 {} 的性质是 {:?}，但处于 {:?} 位（期望 {:?}）",
                        i + 1, actual_nature, yao_pos, expected_nature
                    ),
                });

                // 找到更合适的位置
                if let Some(better_pos) = self.find_better_position(actual_nature, i) {
                    suggestions.push(SequenceSuggestion {
                        action: SuggestionAction::Reorder {
                            from: i,
                            to: better_pos,
                        },
                        description: format!(
                            "建议将步骤 {} 移动到位置 {}",
                            i + 1, better_pos + 1
                        ),
                        expected_benefit: "使步骤顺序更符合爻位特性，降低执行风险".to_string(),
                    });
                }
            }
        }

        // 2. 检查是否缺少关键步骤类型
        let natures: Vec<_> = self.steps.iter()
            .map(|s| StepAnalyzer::analyze_nature(s))
            .collect();

        if !natures.contains(&StepNature::Preparation) {
            suggestions.push(SequenceSuggestion {
                action: SuggestionAction::AddStep {
                    at: 0,
                    nature: StepNature::Preparation,
                },
                description: "建议在开始添加准备步骤（如：检查环境、读取配置）".to_string(),
                expected_benefit: "确保执行环境就绪，避免后续错误".to_string(),
            });
        }

        if !natures.contains(&StepNature::Cleanup) && self.steps.len() > 3 {
            suggestions.push(SequenceSuggestion {
                action: SuggestionAction::AddStep {
                    at: self.steps.len(),
                    nature: StepNature::Cleanup,
                },
                description: "建议在结尾添加清理步骤（如：关闭连接、保存状态）".to_string(),
                expected_benefit: "确保资源正确释放，避免泄漏".to_string(),
            });
        }

        // 3. 检查步骤数量是否合理
        if self.steps.len() > 9 {
            suggestions.push(SequenceSuggestion {
                action: SuggestionAction::Split { at: self.steps.len() / 2 },
                description: format!(
                    "任务步骤较多（{}步），建议拆分为多个子任务",
                    self.steps.len()
                ),
                expected_benefit: "降低单次执行的复杂度，提高成功率".to_string(),
            });
        }

        SequenceValidation {
            is_valid: issues.is_empty(),
            issues,
            suggestions,
        }
    }

    fn calculate_severity(actual: StepNature, expected: StepNature) -> IssueSeverity {
        use StepNature::*;

        match (actual, expected) {
            // 关键位置错误：严重
            (_, Decision) | (Decision, _) => IssueSeverity::Critical,
            (_, Preparation) | (Preparation, _) => IssueSeverity::Critical,

            // 中等位置错误：警告
            (Execution, Processing) | (Processing, Execution) => IssueSeverity::Warning,

            // 轻微位置错误：信息
            _ => IssueSeverity::Info,
        }
    }

    fn find_better_position(&self, nature: StepNature, current: usize) -> Option<usize> {
        // 根据性质找到更合适的位置
        match nature {
            StepNature::Preparation => Some(0),
            StepNature::Cleanup => Some(self.steps.len() - 1),
            StepNature::Decision => {
                // 决策步骤应该在三爻（中间偏前）
                Some(self.steps.len() / 2)
            }
            _ => None,
        }
    }
}
```

### Phase 2: 态势评估系统（v1.36.1 继续）

#### 2.1 基于科学的态势评估

**新增模块**：`src/agent/divination/situation_analyzer.rs`

```rust
/// 态势分析结果
pub struct SituationAnalysis {
    /// 复杂度级别
    pub complexity: ComplexityLevel,

    /// 风险等级
    pub risk: RiskLevel,

    /// 时序分析
    pub timing: TimingAnalysis,

    /// 顺序验证
    pub sequence_validation: SequenceValidation,

    /// 优化建议
    pub suggestions: Vec<OptimizationSuggestion>,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum ComplexityLevel {
    Simple,    // ≤3步，阴阳平衡
    Moderate,  // 4-6步，略有偏重
    Complex,   // >6步，明显失衡
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum RiskLevel {
    Low,      // 无不确定步骤
    Medium,   // 1-2个不确定步骤
    High,     // ≥3个不确定步骤
}

pub struct TimingAnalysis {
    /// 是否有时间依赖
    pub has_time_dependency: bool,

    /// 是否有时间约束
    pub has_time_constraint: bool,

    /// 建议的执行时间
    pub suggested_execution_time: Option<DateTime<Utc>>,

    /// 时序问题
    pub timing_issues: Vec<String>,
}

impl SituationAnalyzer {
    pub fn analyze(plan: &ExecutionPlan) -> SituationAnalysis {
        SituationAnalysis {
            complexity: Self::analyze_complexity(plan),
            risk: Self::analyze_risk(plan),
            timing: Self::analyze_timing(plan),
            sequence_validation: plan.validate_sequence(),
            suggestions: Self::generate_suggestions(plan),
        }
    }

    fn analyze_complexity(plan: &ExecutionPlan) -> ComplexityLevel {
        let step_count = plan.steps.len();

        // 计算阴阳配比
        let yin_steps = plan.steps.iter()
            .filter(|s| Self::is_yin_step(s))
            .count();
        let yang_steps = step_count - yin_steps;

        let balance = (yin_steps as f64 - yang_steps as f64).abs() / step_count as f64;

        if step_count <= 3 && balance < 0.3 {
            ComplexityLevel::Simple
        } else if step_count <= 6 && balance < 0.5 {
            ComplexityLevel::Moderate
        } else {
            ComplexityLevel::Complex
        }
    }

    fn is_yin_step(step: &Step) -> bool {
        // 阴性步骤：读取、等待、观察
        matches!(
            StepAnalyzer::analyze_nature(step),
            StepNature::Preparation | StepNature::Decision
        )
    }

    fn analyze_risk(plan: &ExecutionPlan) -> RiskLevel {
        let uncertain_count = plan.steps.iter()
            .filter(|s| Self::is_uncertain_step(s))
            .count();

        match uncertain_count {
            0 => RiskLevel::Low,
            1..=2 => RiskLevel::Medium,
            _ => RiskLevel::High,
        }
    }

    fn is_uncertain_step(step: &Step) -> bool {
        // 不确定步骤：可能失败或需要外部输入
        step.tool.contains("search")
            || step.tool.contains("network")
            || step.tool.contains("api")
            || step.description.contains("如果")
            || step.description.contains("尝试")
    }

    fn analyze_timing(plan: &ExecutionPlan) -> TimingAnalysis {
        TimingAnalysis {
            has_time_dependency: plan.steps.iter().any(|s| {
                s.description.contains("等待") || s.description.contains("定时")
            }),
            has_time_constraint: plan.total_estimated_time > 60.0,
            suggested_execution_time: None,  // 后续实现
            timing_issues: vec![],           // 后续实现
        }
    }

    fn generate_suggestions(plan: &ExecutionPlan) -> Vec<OptimizationSuggestion> {
        let mut suggestions = vec![];

        // 基于复杂度的建议
        match Self::analyze_complexity(plan) {
            ComplexityLevel::Complex => {
                suggestions.push(OptimizationSuggestion {
                    priority: SuggestionPriority::High,
                    description: "任务较为复杂，建议拆分为多个子任务".to_string(),
                    expected_improvement: "降低单次执行复杂度，提高成功率".to_string(),
                });
            }
            _ => {}
        }

        // 基于风险度的建议
        match Self::analyze_risk(plan) {
            RiskLevel::High => {
                suggestions.push(OptimizationSuggestion {
                    priority: SuggestionPriority::High,
                    description: "存在多个不确定步骤，建议增加错误处理和检查点".to_string(),
                    expected_improvement: "提高容错能力，避免级联失败".to_string(),
                });
            }
            RiskLevel::Medium => {
                suggestions.push(OptimizationSuggestion {
                    priority: SuggestionPriority::Medium,
                    description: "存在不确定步骤，建议添加验证".to_string(),
                    expected_improvement: "及时发现问题，避免后续浪费".to_string(),
                });
            }
            _ => {}
        }

        suggestions
    }
}
```

#### 3.2 实现上下文感知的 Intent 匹配

**新增模块**：`src/dsl/intent/context_aware_matcher.rs`

```rust
use super::*;
use chrono::Utc;

pub struct ContextAwareMatcher {
    basic_matcher: IntentMatcher,
}

impl ContextAwareMatcher {
    /// 基于上下文的智能匹配
    pub fn match_with_context(
        &self,
        query: &str,
        context: &ExecutionContext,
    ) -> Option<ContextEnhancedPlan> {
        // 1. 基础匹配
        let candidates = self.basic_matcher.match_candidates(query);

        // 2. 上下文过滤和增强
        let enhanced: Vec<_> = candidates
            .into_iter()
            .filter_map(|intent| self.enhance_with_context(intent, context))
            .collect();

        // 3. 选择最佳方案
        enhanced.into_iter().max_by_key(|p| p.suitability_score)
    }

    fn enhance_with_context(
        &self,
        intent: Intent,
        context: &ExecutionContext,
    ) -> Option<ContextEnhancedPlan> {
        let mut plan = intent.to_execution_plan();
        let mut notes = vec![];
        let mut suitability_score = 100;

        // 天时检查
        if let Some(timing_req) = &intent.context_requirements.timing {
            let timing_result = self.check_timing(timing_req, context.current_time);

            if !timing_result.is_suitable {
                suitability_score -= 30;
                notes.push(timing_result.note);
            }

            if let Some(better_time) = timing_result.suggested_time {
                plan.add_note(format!("建议在 {} 执行以获得最佳效果", better_time));
            }
        }

        // 地利检查
        if let Some(location_req) = &intent.context_requirements.location {
            let location_result = self.check_location(location_req, context);

            if !location_result.is_suitable {
                suitability_score -= 20;
                notes.push(location_result.note);
            }

            if location_result.has_issues {
                return None;  // 关键资源不足，直接过滤
            }
        }

        // 人和检查
        if let Some(knowledge_req) = &intent.context_requirements.knowledge {
            let knowledge_result = self.check_knowledge(knowledge_req, context);

            if knowledge_result.has_best_practices {
                plan.apply_best_practices(knowledge_result.practices);
                notes.push("已应用最佳实践".to_string());
            }

            if knowledge_result.has_warnings {
                plan.add_warnings(knowledge_result.warnings);
                suitability_score -= 10;
            }
        }

        Some(ContextEnhancedPlan {
            plan,
            suitability_score,
            context_notes: notes,
        })
    }

    fn check_timing(
        &self,
        req: &TimingRequirements,
        current_time: DateTime<Utc>,
    ) -> TimingCheckResult {
        // 实现时间检查逻辑
        // ...
        TimingCheckResult {
            is_suitable: true,
            suggested_time: None,
            note: String::new(),
        }
    }

    fn check_location(
        &self,
        req: &LocationRequirements,
        context: &ExecutionContext,
    ) -> LocationCheckResult {
        // 实现地理和资源检查逻辑
        // ...
        LocationCheckResult {
            is_suitable: true,
            has_issues: false,
            note: String::new(),
        }
    }

    fn check_knowledge(
        &self,
        req: &KnowledgeRequirements,
        context: &ExecutionContext,
    ) -> KnowledgeCheckResult {
        // 实现知识和信息检查逻辑
        // ...
        KnowledgeCheckResult {
            has_best_practices: false,
            practices: vec![],
            has_warnings: false,
            warnings: vec![],
        }
    }
}
```
