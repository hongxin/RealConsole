### 方向 A：简化流程（推荐）⚡

**哲学依据**：
> "大道至简" - 最小改动，最大收益

**改动范围**：1 行代码
**预计时间**：5 分钟
**风险等级**：极低

**实施方案**：

```javascript
// 文件：src/web/frontend.rs
// 位置：confirmEditMode() 函数（约 line 1391）

confirmEditMode(planId) {
    console.log(`[v1.37.0 DEBUG] Confirming edit mode for plan: ${planId}`);

    const editState = this.editMode.get(planId);
    if (!editState) {
        console.error(`[v1.37.0 ERROR] Edit state not found: ${planId}`);
        return;
    }

    // Exit edit mode
    editState.editing = false;
    this.editMode.set(planId, editState);

    // Re-render normal mode
    this.renderNormalMode(planId);

    // 🆕 v1.37.0: 保存后立即执行
    this.executePlan(planId);  // ← 新增这一行
}
```

**用户体验提升**：
```
改动前（3步）:
1. 点击"修改计划"
2. 勾选步骤
3. 点击"保存"
4. 点击"执行计划" ← 消除这一步

改动后（2步）:
1. 点击"修改计划"
2. 勾选步骤
3. 点击"保存并执行" ← 自动执行
```

**优点**：
- ✅ 改动最小（1-2 行代码）
- ✅ 用户流程简化（3步 → 2步）
- ✅ 保持现有交互模式（内联编辑）

**2. 修改 enterEditMode() 方法**：
```javascript
enterEditMode(planId) {
    const plan = this.intentPlans.get(planId);
    if (!plan) return;

    // 创建并显示模态对话框
    const dialog = this.createEditDialog(plan);
    document.body.insertAdjacentHTML('beforeend', dialog);

    // 绑定事件
    const modal = document.querySelector('.intent-edit-modal');
    const cancelBtn = modal.querySelector('.dialog-cancel-btn');
    const confirmBtn = modal.querySelector('.dialog-confirm-btn');
    const checkboxes = modal.querySelectorAll('input[type="checkbox"]');

    // 取消按钮
    cancelBtn.addEventListener('click', () => {
        modal.remove();
    });

    // 确认按钮
    confirmBtn.addEventListener('click', () => {
        // 更新步骤启用状态
        checkboxes.forEach(checkbox => {
            const stepIndex = parseInt(checkbox.dataset.stepIndex);
            plan.steps[stepIndex].enabled = checkbox.checked;
        });

        // 关闭对话框
        modal.remove();

        // 立即执行
        this.executePlan(planId);
    });
}
```

**优点**：
- ✅ 更现代的交互体验
- ✅ 聚焦用户注意力（模态对话框）
- ✅ 明确的确认/取消流程
- ✅ 一步完成（修改 → 确认并执行）

**缺点**：
- ⚠️  需要实现模态对话框组件（~200行代码）
- ⚠️  需要处理更多交互细节（点击外部关闭等）
- ⚠️  需要 1-2 天开发和测试时间
