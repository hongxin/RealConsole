## 📋 功能概述

v1.38.0 为 RealConsole Web 终端实现了 **Cell 重新执行** (Rerun Cell) 功能，允许用户点击按钮重新执行历史命令/对话，类似 Jupyter Notebook 的 cell 重执行机制。

## ✨ 核心特性

### 1. UI 按钮设计
- **位置**: 每个 Round 卡片头部右侧（折叠按钮之前）
- **样式**: 赛博朋克风格
  - 背景：青色到绿色渐变 (`linear-gradient(90deg, #00f0ff 0%, #39ff14 100%)`)
  - 文字：黑色粗体 (`color: #000`, `font-weight: 600`)
  - 效果：发光阴影 + Hover 放大 1.05 倍
- **文字**: "🔄 重新执行"
- **交互**: 点击后立即禁用，执行完成后恢复

### 2. 执行流程
```
用户点击 → 禁用按钮 → 清空输出 → 发送 WebSocket → 后端处理 → 新输出 → 恢复按钮
```

**详细步骤**:
1. 前端捕获点击事件 (`rerunCell()`)
2. 禁用按钮，显示 "⏳ 执行中..."
3. 清空输出区域，显示 "🔄 正在重新执行..."
4. 发送 WebSocket 消息: `{type: 'rerun_cell', round_id: '...'}`
5. 后端接收，发送 `clear_cell` 消息
6. 后端重新执行原始输入 (`handle_input()`)
7. 输出流式返回，更新 UI
8. 执行完成后恢复按钮状态

### 3. 错误处理
- **WebSocket 未连接**: 显示红色错误信息 "❌ WebSocket 未连接，无法重新执行"
- **Round 不存在**: 后端返回错误消息
- **快速连续点击**: 按钮禁用机制防止重复提交

#### 3. 核心处理函数 (`src/web/websocket.rs`, Line 1382-1429)

```rust
async fn handle_rerun_cell(
    session: &Arc<Session>,
    round_id: &str,
    sender: &mut futures::stream::SplitSink<WebSocket, Message>,
) -> anyhow::Result<()> {
    // 1. 从 session 中查找原始输入
    let original_input = {
        let rounds = session.rounds.read().await;
        rounds
            .iter()
            .find(|r| r.id == round_id)
            .map(|r| r.user_input.clone())
    };

    let input_content = match original_input {
        Some(content) => content,
        None => {
            // Round 不存在
            let error_msg = ServerMessage::Error {
                content: format!("Round {} not found", round_id),
            };
            sender
                .send(Message::Text(serde_json::to_string(&error_msg)?))
                .await?;
            return Ok(());
        }
    };

    println!("[v1.38.0] Rerunning cell: round_id={}, input={}", round_id, ...);

    // 2. 发送 clear_cell 消息
    let clear_msg = ServerMessage::ClearCell {
        round_id: round_id.to_string(),
    };
    sender.send(Message::Text(serde_json::to_string(&clear_msg)?)).await?;

    // 3. 重新执行输入
    handle_input(session, &input_content, sender).await?;

    Ok(())
}
```

#### 3. rerunCell() 方法 (`src/web/frontend.rs`, Line 1034-1091)

```javascript
rerunCell(roundId) {
    console.log(`[v1.38.0] Rerunning cell: ${roundId}`);

    const round = this.rounds.find(r => r.id === roundId);
    if (!round) {
        console.error(`[v1.38.0 ERROR] Round not found: ${roundId}`);
        return;
    }

    // 1. 禁用按钮
    const rerunBtn = round.element.querySelector('.round-rerun-btn');
    if (rerunBtn) {
        rerunBtn.disabled = true;
        rerunBtn.textContent = '⏳ 执行中...';
        rerunBtn.style.opacity = '0.6';
        rerunBtn.style.cursor = 'not-allowed';
    }

    // 2. 清空输出
    const outputContent = round.element.querySelector('.output-content');
    if (outputContent) {
        outputContent.innerHTML = `
            <div class="loading-spinner">🔄 正在重新执行...</div>
        `;
    }

    // 3. 发送 WebSocket 消息
    if (this.ws && this.ws.readyState === WebSocket.OPEN) {
        this.ws.send(JSON.stringify({
            type: 'rerun_cell',
            round_id: roundId
        }));
    } else {
        // WebSocket 未连接错误处理
        if (outputContent) {
            outputContent.innerHTML = `
                <div style="color: #ff006e; padding: 1em;">
                    ❌ WebSocket 未连接，无法重新执行
                </div>
            `;
        }
        // 恢复按钮
        if (rerunBtn) {
            rerunBtn.disabled = false;
            rerunBtn.textContent = '🔄 重新执行';
            rerunBtn.style.opacity = '1';
            rerunBtn.style.cursor = 'pointer';
        }
    }
}
```

## 🐛 Bug 修复记录

### Bug #1: WebSocket 未连接

**问题**: 测试时点击"重新执行"按钮报错: "❌ WebSocket 未连接，无法重新执行"

**原因**:
- `rerunCell()` 方法访问 `this.ws`
- 但 WebSocket 对象 `ws` 是主函数中的局部变量
- 从未保存到 `terminal` 对象

**定位过程**:
1. 搜索 WebSocket 创建: 发现 `const ws = new WebSocket(wsUrl);` (Line 1880)
2. 搜索 `terminal.ws`: 未找到赋值语句
3. 确认 `ws.send()` 在主作用域可用，但 `terminal` 方法无法访问

**修复方案**: 在 `src/web/frontend.rs` Line 1883 添加:

```javascript
// v1.38.0: 保存 WebSocket 引用到 terminal 对象（用于重新执行功能）
terminal.ws = ws;
```

**验证结果**:
- 重新编译: `cargo build --release` ✅
- 重启服务器: PID 5497, 端口 7799 ✅
- 测试日志 (`/tmp/v1.38.0_fixed.log`):
