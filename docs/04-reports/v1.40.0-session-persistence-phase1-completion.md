## 📝 数据结构设计

### LocalStorage Keys

```javascript
'realconsole_current_session'     // 当前活动会话（完整数据）
'realconsole_session_history'      // 历史会话列表（元数据）
'realconsole_session_config'       // 用户配置
'realconsole_session_{UUID}'       // 历史会话数据（按 ID）
```

### 数据结构

**SerializableSession**:
```javascript
{
    id: string,
    name: string,
    created_at: string,  // ISO 8601
    updated_at: string,
    conversation_id: string,
    rounds: Array<ConversationRound>,
    metadata: object,
    version: string
}
```

**SessionHistoryItem**:
```javascript
{
    id: string,
    name: string,
    created_at: string,
    updated_at: string,
    round_count: number,
    preview: string,     // 前 50 字符
    size: number         // 字节数
}
```

**SessionConfig**:
```javascript
{
    auto_save: boolean,        // 默认 true
    max_history: number,       // 默认 10
    max_age_days: number,      // 默认 30
    save_on_exit: boolean,     // 默认 true
    auto_restore: boolean      // 默认 true
}
```

## 🎨 设计亮点

### 1. 易变哲学体现

**三态清理策略**:
1. **保留态** - 在数量和时间限制内的会话
2. **清理态** - 超过限制的旧会话自动删除
3. **警告态** - 超过存储配额时主动清理

### 2. 极简主义实践

**代码简洁**:
- 单一职责：LocalStorageManager 专注于浏览器端持久化
- 清晰分层：配置/当前/历史/清理 四个模块
- 完整日志：每个操作都有日志记录，便于调试

**用户友好**:
- 自动清理：用户无需手动管理存储空间
- 智能配置：默认值适合大多数用户
- 安全操作：所有方法都有 try-catch 保护

### 3. 性能优化

**空间管理**:
- 历史列表（元数据）单独存储，轻量级
- 完整会话数据按需加载（`getHistoryItem()`）
- 超过 8MB 自动清理，避免配额问题

**时间管理**:
- 页面加载时清理过期会话（一次性操作）
- 历史列表按更新时间倒序，最近的优先显示

**预计时间**: 2-3 小时

**示例代码**:
```javascript
class HybridTerminal {
    constructor() {
        // ... 现有代码

        // v1.40.0: 浏览器端持久化
        this.localStorage = new LocalStorageManager();
        this.sessionId = null;
        this.sessionCreatedAt = null;

        this.setupAutoSave();
    }

    setupAutoSave() {
        // 页面退出时保存
        window.addEventListener('beforeunload', () => {
            if (this.localStorage.config.save_on_exit) {
                this.saveCurrentSession();
            }
        });

        // 定期自动保存（每 5 分钟）
        if (this.localStorage.config.auto_save) {
            setInterval(() => {
                this.saveCurrentSession();
            }, 5 * 60 * 1000);
        }
    }

    saveCurrentSession() {
        if (this.rounds.length === 0) return;

        const session = {
            id: this.sessionId || this.localStorage.generateUUID(),
            name: this.generateSessionName(),
            created_at: this.sessionCreatedAt || new Date().toISOString(),
            updated_at: new Date().toISOString(),
            conversation_id: this.conversationId,
            rounds: this.rounds,
            version: '1.0'
        };

        this.localStorage.saveCurrentSession(session);
    }

    restoreSession(session) {
        console.log('[Session] Restoring:', session.name);

        this.sessionId = session.id;
        this.conversationId = session.conversation_id;
        this.sessionCreatedAt = session.created_at;

        // 恢复所有 Round
        session.rounds.forEach(round => {
            this.createRound(round);
            this.completeRound(round);
        });

        this.scrollToBottom();
        this.showNotification(`✅ 已恢复会话：${session.name}`);
    }
}
```
