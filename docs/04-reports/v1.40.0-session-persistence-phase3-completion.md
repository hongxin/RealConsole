#### 1.1 构造函数和初始化

```javascript
constructor(terminal) {
    this.terminal = terminal;
    this.listContainer = document.getElementById('session-list');
    this.saveBtn = document.getElementById('save-session-btn');
    this.refreshBtn = document.getElementById('refresh-sessions-btn');
    this.panelCloseBtn = document.getElementById('session-panel-close');
    this.panel = document.getElementById('session-panel');

    this.setupEventListeners();
}
```

**初始化流程**:
1. 保存 terminal 引用
2. 获取所有 DOM 元素引用
3. 设置事件监听器

#### 1.2 事件监听器设置

**setupEventListeners() 方法** (lines 2731-2752):

```javascript
setupEventListeners() {
    // 保存当前会话到历史
    if (this.saveBtn) {
        this.saveBtn.onclick = () => this.saveCurrentSession();
    }

    // 刷新会话列表
    if (this.refreshBtn) {
        this.refreshBtn.onclick = () => this.refreshSessionList();
    }

    // 关闭面板
    if (this.panelCloseBtn) {
        this.panelCloseBtn.onclick = () => this.closePanel();
    }

    // 点击遮罩层关闭
    const overlay = this.panel?.querySelector('.session-panel-overlay');
    if (overlay) {
        overlay.onclick = () => this.closePanel();
    }
}
```

**绑定的事件**:
- 💾 保存按钮 → `saveCurrentSession()`
- 🔄 刷新按钮 → `refreshSessionList()`
- ✕ 关闭按钮 → `closePanel()`
- 遮罩层点击 → `closePanel()`

#### 1.5 刷新会话列表

**refreshSessionList() 方法** (lines 2823-2839):

**流程**:

3. 遍历列表，渲染每个会话项
4. 绑定会话项的事件（加载、删除）

#### 1.7 绑定会话项事件

**bindSessionItemEvents() 方法** (lines 2866-2878):

```javascript
bindSessionItemEvents() {
    // 加载按钮
    const loadBtns = this.listContainer.querySelectorAll('.session-load-btn');
    loadBtns.forEach(btn => {
        btn.onclick = () => this.loadSession(btn.dataset.id);
    });

    // 删除按钮
    const deleteBtns = this.listContainer.querySelectorAll('.session-delete-btn');
    deleteBtns.forEach(btn => {
        btn.onclick = () => this.deleteSession(btn.dataset.id);
    });
}
```

#### 1.8 加载历史会话

**loadSession() 方法** (lines 2883-2909):

**流程**:
1. 从 LocalStorage 加载完整会话数据
2. 检查会话是否存在
3. 如果当前有未保存的会话，提示用户确认
4. 调用 `terminal.restoreSession()` 恢复会话
5. 关闭面板

**用户确认**:
```javascript
if (this.terminal.rounds.length > 0) {
    if (!confirm('加载会话将覆盖当前内容，是否继续？\n\n建议先保存当前会话。')) {
        return;
    }
}
```

#### 1.9 删除历史会话

**deleteSession() 方法** (lines 2914-2929):

**流程**:
1. 提示用户确认删除（不可撤销）
2. 调用 `localStorage.deleteHistoryItem()` 删除
3. 刷新列表显示

## 🎨 设计亮点

### 1. 用户体验优化

**可视化管理**:
- 点击"💾 会话"按钮打开面板
- 网格布局显示所有历史会话
- 每个会话显示名称、回合数、时间、大小

**智能提示**:
- 保存成功: `✅ 会话已保存到历史：${name}`
- 加载确认: 提示覆盖当前内容，建议先保存
- 删除确认: 提示操作不可撤销
- 空列表: "暂无保存的会话"

**操作流畅**:
- 保存后自动刷新列表
- 加载后自动关闭面板
- 删除后立即更新显示

### 2. 易变哲学体现

**三态会话状态**:
1. **当前态** - 正在使用的会话（自动保存）
2. **历史态** - 保存到历史的会话（可加载）
3. **存档态** - 超过限制自动清理（Phase 1 已实现）

**三态操作模式**:
1. **查看态** - 浏览历史会话列表
2. **加载态** - 恢复历史会话继续工作
3. **管理态** - 保存/删除会话

### 3. 极简主义实践

**单一职责**:
- SessionManager: 仅负责 UI 交互和显示
- LocalStorageManager: 仅负责数据存储
- HybridTerminal: 仅负责会话恢复

**清晰接口**:
- `openPanel()` / `closePanel()` - 面板控制
- `saveCurrentSession()` - 保存会话
- `loadSession(id)` - 加载会话
- `deleteSession(id)` - 删除会话
- `refreshSessionList()` - 刷新列表

**最小化依赖**:
- 复用 Phase 1 的 LocalStorageManager
- 复用 Phase 2 的 restoreSession()
- 无需引入额外库

### 4. 护眼配色一致性

**紫灰配色**:
- 主题色: #A371F7（紫色）
- 文本色: #E6EDF3（GitHub 白）
- 次要色: #8B949E（GitHub 灰）
- 警告色: #FF6B6B（柔和红）

**避免刺眼颜色**:
- ❌ 不使用亮青色（#00ffff）
- ❌ 不使用霓虹绿（#39ff14）
- ✅ 使用柔和紫色和灰色

## 🚀 使用场景

### 场景 1: 保存重要会话

**用户操作**:
1. 完成一个复杂的开发任务（20+ Round）
2. 点击"💾 会话"打开面板
3. 点击"💾 保存当前会话"
4. 看到提示"✅ 会话已保存到历史：调试网络超时问题..."

**系统行为**:

- 列表自动刷新显示新保存的会话

**用户操作**:
1. 打开面板，看到 5 个历史会话
2. 找到"实现用户认证模块..."会话
3. 点击"📂 加载"
4. 确认覆盖当前内容

**系统行为**:
- 清空当前对话
- 恢复历史会话的所有 Round
- 保持原有时间戳和元数据
- 视觉上无缝衔接

### 场景 3: 管理历史会话

**用户操作**:
1. 打开面板，看到 10 个历史会话（达到上限）

**系统行为**:

**用户操作**:
1. 打开面板，看到按时间倒序的会话列表

**显示信息**:

## 💡 技术债务

### 已知限制

1. **无导出功能**
   - 当前: 仅支持 LocalStorage 存储
   - 计划: 未来添加导出为 Markdown/JSON（可选功能）

2. **无搜索/筛选**
   - 当前: 按时间倒序显示所有会话
   - 计划: 添加搜索和筛选功能（如按日期、关键词）

3. **无会话重命名**
   - 当前: 会话名称自动生成，不可修改
   - 计划: 允许用户自定义会话名称

4. **无会话合并**
   - 当前: 每个会话独立
   - 计划: 支持合并多个会话

### 待优化项

1. **Toast 通知**
   - 当前: 使用 `alert()` 提示
   - 建议: 实现轻量级 Toast 组件（更优雅）

2. **加载动画**
   - 当前: 无加载状态提示
   - 建议: 加载会话时显示 Loading 动画

3. **会话预览**
   - 当前: 仅显示元数据
   - 建议: 悬停时显示前几条对话预览
