## 🎯 目标

让 Web Terminal 的会话能够在浏览器中持久化，实现：

1. **自动保存** - 用户操作时自动保存到 LocalStorage
2. **自动恢复** - 刷新页面后自动加载最后的会话
3. **历史管理** - 查看和管理多个历史会话
4. **灵活配置** - 用户可配置保留策略（数量/时间）

### Phase 2: 自动保存与恢复

#### 2.1 自动保存机制

**触发时机**:
1. 每个 Round 完成后
2. 用户显式点击"保存"按钮
3. 页面 beforeunload 事件（退出前）

**实现**:
```javascript
class HybridTerminal {
    constructor() {
        this.sessionStorage = new SessionStorage();
        this.autoSaveEnabled = true;
        this.setupAutoSave();
    }

    setupAutoSave() {
        // 页面退出时保存
        window.addEventListener('beforeunload', () => {
            if (this.sessionStorage.config.save_on_exit) {
                this.saveCurrentSession();
            }
        });

        // 定期自动保存（每 5 分钟）
        if (this.sessionStorage.config.auto_save) {
            setInterval(() => {
                this.saveCurrentSession();
            }, 5 * 60 * 1000);
        }
    }

    saveCurrentSession() {
        if (this.rounds.length === 0) return;

        const session = {
            id: this.sessionId || generateUUID(),
            name: this.generateSessionName(),
            created_at: this.sessionCreatedAt || new Date().toISOString(),
            updated_at: new Date().toISOString(),
            conversation_id: this.conversationId,
            rounds: this.rounds,
            metadata: this.calculateMetadata(),
            version: '1.0'
        };

        this.sessionStorage.saveCurrentSession(session);
        console.log('[Session] Auto-saved:', session.name);
    }
}
```

#### 2.2 自动恢复机制

**触发时机**: `DOMContentLoaded` 事件

**实现**:
```javascript
window.addEventListener('DOMContentLoaded', () => {
    const terminal = new HybridTerminal();

    // 尝试恢复最后的会话
    if (terminal.sessionStorage.config.auto_restore) {
        const savedSession = terminal.sessionStorage.loadCurrentSession();
        if (savedSession && savedSession.rounds.length > 0) {
            terminal.restoreSession(savedSession);
        }
    }

    terminal.connect();
});

// HybridTerminal 新增方法
restoreSession(session) {
    console.log('[Session] Restoring session:', session.name);

    // 恢复会话元数据
    this.sessionId = session.id;
    this.conversationId = session.conversation_id;
    this.sessionCreatedAt = session.created_at;

    // 恢复所有 Round
    session.rounds.forEach(round => {
        this.renderRound(round);
    });

    // 滚动到底部
    this.scrollToBottom();

    // 显示提示
    this.showNotification(`已恢复会话：${session.name}`);
}
```

    const session = terminal.sessionStorage.getHistoryItem(id);
    if (!session) {
        alert('会话不存在');
        return;
    }

    // 确认是否覆盖当前会话

    closeSessionPanel();
}

### Phase 4: 清理策略

#### 4.1 数量限制

**配置**: `max_history = 10`（默认）

**实现**:
```javascript
enforceMaxHistory() {
    const history = this.getHistory();
    if (history.length > this.config.max_history) {
        // 按时间排序，删除最旧的
        history.sort((a, b) =>
            new Date(a.updated_at) - new Date(b.updated_at)
        );

        const toDelete = history.length - this.config.max_history;
        for (let i = 0; i < toDelete; i++) {
            this.deleteHistoryItem(history[i].id);
        }
    }
}
```

#### 4.2 时间限制

**配置**: `max_age_days = 30`（默认）

**实现**:
```javascript
cleanupOldSessions() {
    const now = new Date();
    const maxAge = this.config.max_age_days * 24 * 60 * 60 * 1000;

    const history = this.getHistory();
    history.forEach(item => {
        const age = now - new Date(item.updated_at);
        if (age > maxAge) {
            this.deleteHistoryItem(item.id);
        }
    });
}
```

#### 4.3 存储空间检查

**LocalStorage 限制**: 通常 5-10MB

**实现**:
```javascript
estimateSize(session) {
    const json = JSON.stringify(session);
    return new Blob([json]).size;
}

checkStorageQuota() {
    try {
        const total = 0;
        for (let key in localStorage) {
            if (key.startsWith('realconsole_')) {
                total += localStorage[key].length;
            }
        }

        // 如果超过 8MB，警告
        if (total > 8 * 1024 * 1024) {
            console.warn('[Session] Storage quota警告:', total / 1024 / 1024, 'MB');
            this.enforceMaxHistory();
        }
    } catch (e) {
        console.error('[Session] Storage quota check failed:', e);
    }
}
```

## 📊 技术债务

### 已知限制

1. **LocalStorage 限制** - 通常 5-10MB
   - 解决方案：定期清理，限制历史数量

2. **隐私模式** - LocalStorage 可能不可用
   - 解决方案：降级为 SessionStorage（刷新后丢失）

3. **跨域问题** - 不同域名无法共享
   - 解决方案：提供导出/导入功能

4. **数据格式演化** - 未来版本可能不兼容
   - 解决方案：版本号字段，迁移逻辑
