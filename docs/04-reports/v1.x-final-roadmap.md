## 🎯 总体目标

1. **稳定性优化** - 修复已知问题，提升系统可靠性
2. **文档完善** - 确保所有文档与代码对齐

4. **技术债偿还** - 清理废弃代码，统一 API 设计
5. **v2.0 准备** - 为架构升级做好基础

### v1.42.0 - 性能优化专项 (5-7 天)

**目标**: 消除性能瓶颈，提升响应速度

#### 优化领域

**1. Intent DSL 性能优化**
- **问题**: 50+ Intent 匹配时，正则表达式串行执行效率低
- **方案**:
  - 引入 Trie 树索引，快速过滤候选 Intent
  - 并行化正则匹配（使用 Rayon）
  - 缓存编译后的正则表达式

**预期提升**: 匹配速度 3-5x

**2. LRU 缓存优化**
- **问题**: 当前缓存命中率约 60%，还有提升空间
- **方案**:
  - 增加缓存容量（100 → 200）
  - 实现分层缓存（热点 Intent 独立缓存）
  - 添加缓存预热（启动时加载常用 Intent）

**预期提升**: 缓存命中率 60% → 80%

**3. Web Terminal 渲染优化**
- **问题**: 长输出渲染时页面卡顿
- **方案**:
  - 虚拟滚动（只渲染可见区域）
  - 延迟渲染（分批渲染大量数据）
  - 使用 RequestAnimationFrame 优化动画

**预期提升**: 支持 10,000+ 行输出流畅滚动

**4. 启动时间优化**
- **问题**: 当前启动约 40ms，可以更快
- **方案**:
  - 延迟加载非核心模块
  - 优化配置文件解析
  - 减少不必要的初始化

**预期提升**: 启动时间 40ms → 25ms

### v1.43.0 - 技术债偿还 (5-7 天)

**目标**: 清理代码，统一 API，提升可维护性

#### 清理清单

**1. 移除废弃 API**
```rust
// 移除已标记为 deprecated 的 API
#[deprecated(since = "1.30.0", note = "Use new API")]
pub fn old_function() { ... }  // 删除

// 移除过时的配置选项
// realconsole.yaml 中已不再使用的字段
```

**2. 统一错误处理**
- **问题**: 错误处理风格不一致（部分用 `anyhow!`，部分用自定义错误）
- **方案**:
  - 统一使用 `thiserror` 定义错误类型
  - 建立完整的错误分类体系
  - 添加错误恢复提示

**示例**:
```rust
#[derive(Debug, thiserror::Error)]
pub enum RealConsoleError {
    #[error("LLM error: {0}")]
    LlmError(String),

    #[error("Intent matching failed: {0}")]
    IntentError(String),

    #[error("Tool execution failed: {0}")]
    ToolError(String),
}
```

**3. 代码质量提升**
- [ ] 运行 Clippy 完整检查，修复所有警告
- [ ] 运行 `cargo fmt` 确保代码格式一致
- [ ] 添加缺失的文档注释（所有 public API）
- [ ] 优化复杂函数（圈复杂度 > 10 的函数）

**4. 测试覆盖率提升**
- **当前**: ~85% 覆盖率
- **目标**: > 90% 覆盖率
- **重点**:
  - Web Terminal 前后端集成测试
  - Intent DSL 边界情况测试
  - 错误恢复路径测试
