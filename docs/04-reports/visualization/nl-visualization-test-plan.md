# v1.51.0 自然语言驱动可视化测试计划

**功能**: 智能 Notebook 核心特性 - 自然语言生成图表
**日期**: 2025-01-23
**状态**: 待测试

## 🎯 测试目标

验证用户可以通过自然语言描述直接生成各种图表，无需记忆复杂的命令语法。

## ✨ 核心特性

1. **零学习成本**: 用户直接用自然语言描述需求
2. **智能理解**: LLM 自动识别图表类型、数据和参数
3. **即时反馈**: 实时生成并渲染图表
4. **历史记录**: 自动保存到会话图表历史

## 📋 测试用例

### 测试用例 1: 折线图（Line Chart）

**输入**:
```
帮我画一个销售趋势折线图，X轴是1月到6月，销售额分别是120、132、101、134、90、230
```

**预期结果**:
- ✅ LLM 调用 `create_chart` 工具
- ✅ 参数正确：
  - `chart_type`: "line"
  - `title`: "销售趋势" 或类似
  - `x_labels`: ["1月", "2月", "3月", "4月", "5月", "6月"]
  - `series`: [{"name": "销售额", "data": [120, 132, 101, 134, 90, 230]}]
- ✅ 图表渲染成功
- ✅ 显示消息: "✅ 图表已生成"
