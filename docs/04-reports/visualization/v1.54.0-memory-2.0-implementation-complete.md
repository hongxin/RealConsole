### 2.2 核心数据结构

#### MemoryStateVector（9 维状态向量）

```rust
pub struct MemoryStateVector {
    // 内容维度 (3D)
    pub text_weight: f64,         // 文本权重
    pub visual_weight: f64,       // 视觉权重
    pub data_weight: f64,         // 数据权重

    // 时间维度 (3D)
    pub working_relevance: f64,   // 工作相关性（短期）
    pub session_relevance: f64,   // 会话相关性（中期）
    pub long_term_value: f64,     // 长期价值

    // 智能维度 (3D)
    pub perception_score: f64,    // 感知得分
    pub understanding_score: f64, // 理解得分
    pub orchestration_score: f64, // 编排得分
}
```

**核心方法**:
- `lerp(target, t)` - 线性插值实现状态平滑演化
- `overall_score()` - 综合得分计算
- `normalize_content_weights()` - 权重归一化

#### MultimodalChunk（多模态片段）

```rust
pub struct MultimodalChunk {
    pub id: Uuid,
    pub timestamp: DateTime<Utc>,
    pub dimension: DataDimension,        // 7 大维度之一
    pub content: MultimodalContent,      // 多模态内容
    pub state_vector: MemoryStateVector, // 9 维状态向量
    pub metadata: HashMap<String, Value>,
}
```

**支持的内容类型**:
- `Text` - 文本片段
- `Chart` - 图表数据
- `Image` - 图像数据
- `DataSummary` - 数据摘要
- `SessionSummary` - 会话摘要

### 3.2 理解层（Understanding Layer）

**职责**: 语义分析与相关性评分

```rust
pub struct WebUIUnderstandingLayer {
    keyword_matcher: KeywordMatcher,
    time_decay_config: TimeDecayConfig,
}
```

**核心方法**:
```rust
pub async fn score_relevance(
    &self,
    task: &str,
    chunks: Vec<MultimodalChunk>,
) -> Result<Vec<MultimodalChunk>>
```

**评分算法**:
```rust
understanding_score = (keyword_score * 0.7 + importance * 0.3) * time_decay
```

**关键词匹配**:
- 简单分词 + 停用词过滤
- TF-IDF 简化版（匹配率）
- 支持中英文停用词

**时间衰减**:
```rust
decay = exp(-age_days / half_life_days).max(min_decay)
// 默认: half_life = 7 days, min_decay = 0.1
```

### 3.3 编排层（Orchestration Layer）

**职责**: 上下文优化与 Token 预算管理

```rust
pub struct WebUIOrchestrationLayer {
    token_counter: TokenCounter,
    decision_engine: DecisionEngine,
}
```

**核心方法**:
```rust
pub async fn build_optimized_context(
    &self,
    chunks: Vec<MultimodalChunk>,
    token_budget: usize,
) -> Result<OptimizedMultimodalContext>
```

**贪婪选择算法**:
1. 按 `overall_score()` 降序排列
2. 依次选择片段，累加 token
3. 超出预算时停止
4. 确保最高价值片段优先

**输出结构**:
```rust
pub struct OptimizedMultimodalContext {
    pub text_chunks: Vec<TextChunk>,
    pub chart_references: Vec<ChartReference>,
    pub image_references: Vec<ImageReference>,
    pub data_summaries: Vec<DataSummary>,
    pub recommendations: Vec<Recommendation>,
    pub pre_filled_params: HashMap<String, Value>,
    pub total_tokens: usize,
    pub metadata: ContextMetadata,
}
```

```rust
impl Session {
    pub async fn new(config: Config, registry: CommandRegistry) -> Self {
        // ... 创建 chart_history 和 image_history ...

            eprintln!("[Session] Memory 2.0 智能上下文编排器已初始化");
```

## 8. 哲学映射实现

### 8.1 易经 64 卦决策矩阵

**内卦（8 种内容类型）**:
- 000（坤）→ TextOnly
- 001（艮）→ VisualOnly
- 010（坎）→ DataOnly
- 011（巽）→ TextAndVisual
- 100（震）→ TextAndData
- 101（离）→ VisualAndData
- 110（兑）→ FullMix
- 111（乾）→ Interactive

**外卦（8 种时间情境）**:
- 000（坤）→ CurrentDialog（当下对话）
- 001（艮）→ CurrentSession（当前会话）
- 010（坎）→ RecentSession（近期会话）
- 011（巽）→ MediumTermSession（中期会话）
- 100（震）→ LongTermSession（长期会话）
- 101（离）→ RepeatedPattern（重复模式）
- 110（兑）→ EvolutionTrend（演化趋势）
- 111（乾）→ RareEvent（稀有事件）

**64 卦映射**:
```rust
pub fn get_hexagram(&self) -> Hexagram {
    let inner = self.classify_content();    // 内卦
    let outer = TimeContext::from_age(...); // 外卦
    Hexagram::from_trigrams(inner, outer)   // 组合
}
```

### 8.2 一分为三（9 维向量）

**三大维度，每维度三分**:
- **内容维度** → 文本/视觉/数据
- **时间维度** → 短期/中期/长期
- **智能维度** → 感知/理解/编排

**超越二元对立**:
- ❌ 不是 Relevant / Irrelevant（二分法）
- ✅ 而是 9 维向量空间中的连续演化

### 8.3 状态演化（Lerp）

```rust
pub fn lerp(&self, target: &Self, t: f64) -> Self {
    Self {
        text_weight: self.text_weight + (target.text_weight - self.text_weight) * t,
        // ... 其他维度同理 ...
    }
}
```

**避免离散跳跃，实现平滑过渡**:
- t = 0.0 → 当前状态
- t = 0.5 → 中间状态
- t = 1.0 → 目标状态
