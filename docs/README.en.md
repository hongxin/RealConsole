## Contributing Translations

We welcome contributions to translate documentation into English. Priority documents:

1. **High Priority**: user-guide.md, tool-calling-guide.md
2. **Medium Priority**: tool-development.md, api-reference.md
3. **Lower Priority**: Design documents and reports

**Translation Guidelines**:
- Use `.en.md` suffix for English versions
- Keep technical terms consistent with existing translations
- Preserve the document structure and formatting
- Add bilingual navigation links at the top of each document
